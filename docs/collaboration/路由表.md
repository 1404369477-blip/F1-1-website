# 路由表

> 协议版本:1.4.10 · 更新日期:2026-08-15
> 本表由脚手架确定性生成,新增部门时同步更新,不留“之后手工补路由”的半完成状态。

| 部门 | 角色 ID | 层 | 默认路由 |
|---|---|---|---|
| 统筹部 | `lead` | 管理层 | 接收所有裁决、返工、阻断、审核结论、状态升级与放行回报 |
| 产品部 | `product` | 执行层 | 由统筹部派执行任务;纯澄清可直连;状态变化回统筹部 |
| 研究部 | `research` | 执行层 | 由统筹部派执行任务;纯澄清可直连;状态变化回统筹部 |
| 设计部 | `design` | 执行层 | 由统筹部派执行任务;纯澄清可直连;状态变化回统筹部 |
| 数据部 | `data` | 执行层 | 由统筹部派执行任务;纯澄清可直连;状态变化回统筹部 |
| 开发部 | `dev` | 执行层 | 由统筹部派执行任务;纯澄清可直连;状态变化回统筹部 |
| 安全部 | `security` | 审核层 | 由统筹部派审核任务;审核结论只回统筹部 |
| 测试部 | `test` | 审核层 | 由统筹部派审核任务;审核结论只回统筹部 |
| 自动化部 | `auto` | 执行层 | 由统筹部派执行任务;纯澄清可直连;状态变化回统筹部 |

## 统一路由规则

- 只问一句、不改产物、不改状态的澄清:可直连目标部门。
- 派单、返工、阻断、裁决、需求/范围变更、审核结论、放行、状态升级、增删部门:经统筹部。
- 通知只带任务 ID 和“有新任务 / 已完成 / 遇到阻断”;任务真值在 `tasks/` 中。
