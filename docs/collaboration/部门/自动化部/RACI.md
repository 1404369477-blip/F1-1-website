# 自动化部（M1运行办公室）RACI

| 工作 | M1运行办公室 | 统筹部 | 开发部/数据部 | 安全部/测试部 | 用户 |
|---|---|---|---|---|---|
| 日常只读观察与摘要 | R | A | I | I | I |
| 采集/整理积压诊断 | R | A | C | C | I |
| 隐私最小化流量聚合观察 | R | A | C | C | I |
| 代码或 launchd 候选 | C | A | R | C | I |
| 生产安装/切换/回退 | C | A | R | R（独立门） | G（高风险授权门） |
| DB/schema/发布状态变更 | I | A | R | R（独立门） | G |
| 条件自动发布启用 | I | A | R | R（独立门） | G |
| 事故发现与初报 | R | A | C | C | I |
| 事故复盘与长期修复 | R | A | R | R | C |

`R` 执行，`A` 对结果负责，`G` 用户授权门，`C` 参与复核，`I` 知会。每项只设一个 `A`；M1运行办公室不得同时承担实现和独立放行。
