# M5 与 M1 Codex 机器交接边界

## 推荐结构

采用一个受控“自动化部（M1运行办公室）”，避免多个自由 Agent 互相聊天形成不可审计的隐式状态。

```text
M5 统筹任务真值
  └─ 治理文档与证据指针：共享 docs/collaboration/
       └─ SSH 原子投递：M1 owner-only OpsHandoff/inbox/<taskId>.json
            ├─ lease/<taskId>.json
            ├─ receipts/by-sha/<sha>.json
            └─ outbox/<taskId>/result.json
```

## 强制约束

- 唯一 taskId；合同使用冻结 canonical JSON 和 body SHA。
- 同时只允许一个活动 claimed task；lease 必须有期限、owner、task/body hash，冲突失败关闭。
- 结果必须绑定输入合同、lease、observer receipt 和治理文档 SHA。
- 共享 File Provider 目录只作治理与报告同步，不作队列、锁、lease、授权或完成收据。
- 秘密只允许出现 owner-only path reference，不嵌入合同、prompt、plist、日志或报告。
- “通话”若指 Agent 间文本通信，统一落为 inbox/outbox 合同和收据；语音不是生产控制协议。
