# M1 Codex 模型路由

## DeepSeek V4 Flash

默认处理高频只读状态汇总、收据解析、低风险文档同步、单服务轻诊断和确定性告警归类。

## DeepSeek V4 Pro

用于跨模块诊断、代码或 launchd 候选设计、部署/回退审查、事故复盘、架构判断以及任何复杂或高风险推理任务。

## 共同权限门

- 模型选择不改变任务合同、lease、数据分类、最大调用次数或外传范围。
- 两种模型都不得直接执行生产写、发布、服务重启、launchd 安装或凭证操作。
- 远程推理只有在 task contract 的 `aiInference` 精确绑定 provider、model、允许数据分类和最大调用次数时才允许。
- 源内容、个人数据、秘密、原始流量字段和环境变量值默认不发送。
- 桌面 Scheduled 是否支持这两个模型保持现场 UI `Unknown`；若模型列表不含它们，只能通过已配置的 Codex CLI/provider 和受控只读 launchd 入口运行，不能宣称桌面 Scheduled 支持。
