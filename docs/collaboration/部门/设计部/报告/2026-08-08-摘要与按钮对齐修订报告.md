## 2. 修订设计决策与理由

仅改设计草案 `index.html`（CSS + HTML 结构 + 注释/meta），未触碰 v0.2 视觉语言基线（深浅主题、玻璃克制、trace 悬停浮现、reduced-motion / reduced-transparency、44px 触控、focus-visible 3px 环）。

### 2.1 摘要完整显示（需求①）
| 项 | 决策 | 理由 |
|---|---|---|
| 截断 | 移除 `-webkit-line-clamp` 全部相关属性（`display:-webkit-box`、`-webkit-box-orient`、`overflow:hidden`） | 需求「完整显示、不省略」；摘要是条目正文的一部分，「信息即内容，不藏不漏」 |
| 适用范围 | 全平台（手机端与桌面）一致完整显示 | 需求允许「移动端放开、桌面可保留」，但摘要是简短引言，全平台统一最简洁一致；若仅移动端放开会造成桌面/移动端信息不一致 |
| 可读性 | 保留 `max-width:62ch`（限行宽）与既有 `font-size:14.5px/1.7` | 只限宽度不限高度，长摘要完整可读 |
| 既有成果 | 展开/折叠两态摘要均完整；不改变就地展开、中文提炼、证据行结构 | 不推翻已确认布局 |

### 2.2 回到顶部 + 设置 同一行（需求②）
| 项 | 决策 | 理由 |
|---|---|---|
| 容器 | 新增 `.fab-row`：`position:fixed; right:16px; bottom:16px; display:inline-flex; align-items:center; gap:6px` | 固定定位 flex 行，把两个无框文字按钮稳定排在同一行 |
| 顺序 | DOM：回到顶部 → 设置，flex 行内回到顶部在左、设置在右 | 保持「设置更靠近角落（右）」的功能优先级不变，只是从上下叠放改为左右同行 |
| 命中区 | 两按钮仍 `min-width/min-height:44px`（无视觉框） | 44px 触控目标保留（继承 v0.2i） |
| 设置面板 | `bottom` 从 `calc(16px+44px+44px+8px)` 上移到 `calc(16px+44px+8px)` | 按钮从两行叠放变为一行，面板上移量相应减少一行，仍不遮挡按钮 |

### 2.3 设置与回到顶部同形式（需求③）
- 两按钮共用**同一套**规则（`.fab, .back-to-top`）：`background:transparent`、`border:0`、`border-radius:0`、12.5px/600、`color:var(--muted)`、`text-shadow:var(--ts-1)`；再叠加 `.trace`（默认 `opacity:.5` 隐形 → hover/focus `opacity:1` + `scale(1.04)` + `color:var(--accent)`）。
- 此设计在 v0.2i 已让设置与回到顶部同形式；本次同行重构保持两按钮完全同形式不变，并新增 `role="group"` + `aria-label="右下角工具"` 语义包裹（可访问性不降）。

### 2.4 缩略图底部对齐（需求④）
| 项 | 决策 | 理由 |
|---|---|---|
| `.tl-ev` | `align-items:center` → `align-items:flex-end` | 来源文本（`.evs`）与右侧操作组（`.ev-right`）整体底部对齐 |
| `.ev-right` | `align-items:center` → `align-items:flex-end` | 组内「前往原文 + 缩略图」底部对齐，保证缩略图底边 = 来源文本底边 |
| 窄屏换行 | 390 下 4 图条目（如 r1）缩略图组较宽，`.ev-right` 自然换行到来源文本下一行；2 图（r9）/单图条目仍与来源文本同行底部对齐 | 「同一行横向对齐 + 底部对齐」在窄屏的响应式适配；不推翻已确认缩略图尺寸（28px）与位置（右下角证据行） |

### 2.5 与已确认布局的取舍
- **不推翻**：单主图（原比例限高、不裁切）+ 右下角缩略图、前往原文行内化（11.5px 同排）、时间/日期对齐（时刻上对齐分类、日期下对齐标题）、中文提炼无前言、滑动切图「一次只翻一张」（pointer+wheel 共享手势锁）、移动端版面优化（标题信息块与主图同盒、日期时间左上角、展开垂直居中）全部保持。
- 本次仅改：摘要截断策略、右下角按钮排布（叠放→同行）、缩略图对齐方式（居中→底部）。缩略图尺寸/位置、按钮样式语言均继承不变。
