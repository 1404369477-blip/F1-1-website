## 3. 冻结行为说明

### 3.1 Dock 与右下角工具

- 1440 桌面：回到顶部、设置、主题切换组成固定在视口右下角的同排无框文字工具；外层默认不截获页面点击，具体按钮保持可交互。
- 1024 与 390：底部切换为 Dock。Dock 的渐变模糊背板形成“点击无效区”，由 Dock 本体接收点击，避免操作穿透到下方时间线内容。
- Dock 与按钮底部间距使用 `env(safe-area-inset-bottom, 0px)`，在存在系统安全区时向上避让；当前证据只覆盖普通矩形桌面浏览器视口，未覆盖带真实刘海或 Home Indicator 的实体设备。

### 3.2 设置面板

- 设置按钮切换面板开合；面板展开后，点击面板和设置按钮之外的页面区域会自动收起。
- 语言、来源偏好、通知等只作为“正式设置项待产品确认”的非交互占位骨架；调试控制明确标记为 `DRAFT`，不构成正式产品功能或实现合同。
- 深浅主题由右下角单一主题按钮切换，按钮文字和可访问标签反映当前主题。

### 3.3 多图与媒体

- 多图条目采用一张主图加证据行右侧缩略图；缩略图与左侧来源、作者和时间信息在同一证据行底部对齐。
- 点击缩略图会切换主图；实测首个四图条目从第 1 张切到第 2 张后，主图与激活缩略图的索引均更新为 `1`。
- 冻结 HTML 还包含键盘、悬停预览、触摸或触控板横向滑动、点击主图进入 lightbox、一次滑动只翻一张及滑动后抑制误点击的实现。本轮没有逐一实测这些手势组合，因此它们只作为冻结实现内容记录，不扩大为已验收结论。
- 媒体 URL 与 Google Fonts 仍为外部运行依赖。六张最终证据记录了 2026-08-08 导出时成功加载的状态；离线、CDN 失效、权利变化或生产媒体代理策略不在本冻结任务覆盖范围内。

### 3.4 移动端

- 390 采用单列时间线；日期与时间置于条目上方，标题、摘要、主图和证据行按移动阅读顺序排列。
- 四图条目的来源文本允许收缩，右侧操作组保持单行，缩略图缩小后仍与来源文本底部对齐。
- 底部 Dock 始终覆盖在内容上方并截获其区域点击；页面通过底部留白和安全区变量避免最后内容被系统区域永久遮挡。
