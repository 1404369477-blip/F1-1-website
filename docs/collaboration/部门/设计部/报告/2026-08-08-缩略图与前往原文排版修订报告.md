## 2. 修订设计决策与理由

仅改设计草案 `index.html`（CSS + 模板 + 交互 JS），未触碰 v0.2 token / 视觉语言基线（深浅主题、玻璃克制、trace 悬停浮现、reduced-motion / reduced-transparency、44px 触控、4px 图片硬边、focus-visible 3px 环）。

### 2.1 缩略图新位置：条目右下角证据行，与来源文本同一行
| 项 | 值 | 依据 |
|---|---|---|
| DOM 位置 | `.ph-thumbs` 从 `.tl-media`（主图内部）移出，放入 `.tl-ev`（证据行）右侧 `.ev-right` 簇内 | 需求①「不放在主图内部、放条目右下角、横向对齐来源文本」；`.tl-ev` 即条目底部证据行（信源·作者·时间），来源文本在左、缩略图在右同一行 |
| 对齐方式 | 证据行 `display:flex; align-items:center; justify-content:space-between`：来源文本（`.evs`）左端、缩略图（`.ph-thumbs`）右端，垂直居中同一基线 | 需求①「来源文本左、缩略图右」；断言验证 1440 下 `evs.cy === thumbs.cy`（同一行） |
| 尺寸 | 高 **32px**（桌面）/ **28px**（移动 ≤700px）/ **40px**（`pointer:coarse` 触屏） | 需求①「可以缩小一点」：相对 6838E5 的 40/32px 再缩小；触屏保证命中区（40 + 行距 ≈ 44px，满足契约 §6.4 触控目标） |
| 缩略图样式 | 4px 圆角、`--border` 1.5px 描边（激活 `--accent`）、`opacity:.75 → 1`、hover `scale(1.08)`、focus-visible 描边变 `--focus`；**不再使用深色半透明玻璃底**（已不叠放在照片上，落到页面实色表面） | 位置从「照片之上」变为「表面之上」，玻璃底/降级不再需要；改用 token 描边在深浅主题都可辨识 |
| 窄屏 390 换行 | 来源文本 + 4 张缩略图一屏放不下时，`.ev-right` 作为整体换到下一行并**右对齐**（`margin-left:auto`），即「条目右下角」仍在右下角 | 需求①允许「或按排版合理」；390 下折行右对齐是合理响应式降级 |
| 交互 | 点击切换主图 / 悬停预览 / 移走恢复 / 键盘 Enter/Space 固定 / 滑动切图联动 `is-active` 全部保留（事件宿主从 `.tl-media` 改为 `.tl-item`，因为缩略图已不在媒体区） | 需求①「点击切换主图、悬停预览、键盘可操作保留」；缩略图在条目按钮之外，点击不会误触发手风琴展开/收起（新增断言验证） |
| 主图 | 保持单张 `.ph-main`（原比例、限高、整图缩放不裁切），`.tl-media` 内不再有任何缩略图 | 需求①「主图保持单张放大，主图内部不再放缩略图」 |

### 2.2 前往原文新排版：行内文本，与来源文本同字号同排，仅展开后显示
| 项 | 值 | 依据 |
|---|---|---|
| DOM 位置 | `.tl-original-link` 从 `.tl-detail`（展开区内容末尾）移到 **`.tl-ev` 证据行右侧 `.ev-right` 簇**（在缩略图左侧），与来源文本同一行 | 需求②「对齐详情页面左侧的来源文本」——来源文本所在行即证据行，放同一行即「对齐」 |
| 字号/样式 | **11.5px**（与 `.tl-ev` 来源文本 `font-size` 完全一致）、`--accent` 色、`font-weight:600`、行内 `inline-flex`、hover 下划线 | 需求②「字体大小跟来源文本一致」 |
| 不单独占一行 | 不再 `margin-top:24px` + `min-height:44px` 独占整行；改为 11.5px 行内文本，`min-height:32px`（触屏 44px） | 需求②「不大、不单独占一行、做成行内文本而非大按钮/独立行」 |
| 显示时机 | **仅展开详情后显示**：`.tl-item:not(.is-open) .tl-original-link { display:none }`；折叠时隐藏 | 「前往原文在展开详情后显示」；`.is-open` 由展开/`#open=` 驱动 |
| 证据行 | 仍只保留来源文本（信源 · 作者 · 时间，11.5px faint）；前往原文作为行内操作并入该行右侧 | 与 6838E5「证据行只保留来源文本」一致，仅排版上把前往原文并入该行右端 |

### 2.3 与已确认布局的取舍
- **不推翻**：单张主图、条目右下角缩略图、滑动切图（pointer + wheel）、lightbox、就地展开、深浅主题、trace、降级全部保持。
- **两处细化均属布局级微调**：缩略图从「主图右下角叠放」改为「条目证据行右下角、与来源文本同行」；前往原文从「展开区独立大行」改为「证据行行内小字」。二者都落到同一证据行右侧，视觉上更安静、更紧凑，也解决了「缩略图遮挡主图内容」的既有顾虑（6838E5 未验证项之一）。

## 3. 设计草案修订明细（index.html）

### 3.1 CSS
- `.ph-thumbs`：移除 `position:absolute; right:8px; bottom:8px` 叠层与深色玻璃底/描边/模糊，改为 `display:inline-flex; gap:5px`（390 为 4px）。
- `.ph-thumb`：高 40px → **32px**（390 → 28px，触屏 → 40px）；描边 `--border`、激活 `--accent`、hover `scale(1.08)`、focus-visible `--focus`。
- 新增 `.ev-right`（证据行右侧操作组，`margin-left:auto` 保证窄屏换行右对齐）。
- `.tl-original-link`：11.5px 行内文本、`min-height:32px`（触屏 44px）、`.tl-item:not(.is-open)` 隐藏。
- 移除 `prefers-reduced-transparency` / `[data-rt]` 对 `.ph-thumbs` 的玻璃回退规则（缩略图已不在照片上，无玻璃）。

### 3.2 模板（JS）
- `mediaHTML`：只渲染单张 `.ph-main`（主图内部不再放缩略图）。
- 新增 `thumbsHTML`：多图时在证据行 `.ev-right` 内渲染 `.ph-thumbs`。
- `itemHTML`：`.tl-ev` 改为 `来源文本(.evs) + 右侧簇(.ev-right = 前往原文 + 缩略图)`；`.tl-original` 从 `.tl-detail` 移除。

### 3.3 交互（JS）
- `setMainImage`：缩略图查找宿主从 `.tl-media` 改为 `.tl-item`（`media.closest('.tl-item')`）。
- `bindMedia`：悬停预览 / 移走恢复 / 点击固定 / 键盘 Enter/Space 的事件宿主从 `.tl-media` 改为 `.tl-item`（覆盖证据行内的缩略图）；滑动切图 `bindMainSwipe` 仍绑定 `.tl-media`。
- lightbox `openFrom`：本就以 `.tl-item` 为宿主收集 `.ph-thumb`，无需改动，图集/翻页/Esc/焦点返回不变。
- 其余（swipe 阈值、wheel 冷却、reduced-motion 瞬时、`.is-open` 手风琴）不变。

### 4.1 关键断言（91/91 全过，按面分组）
- **结构**：r1 多图 `multi` + 4 缩略图在 `.tl-ev` 证据行内（`.tl-ev .ph-thumbs` =1）；`.tl-media .ph-thumbs` =0（主图内无缩略图）；`.ph-main` 仅 1 张；单图 r2 无缩略图、非 multi。
- **几何/对齐**：1440 下 `evs.cy === thumbs.cy === orig.cy`（来源文本 / 缩略图 / 前往原文同一行），且 `evs.right < thumbs.left`（来源左、操作右）；缩略图高度 = 32px（1440）/ 28px（390）；390 下折行后簇右端对齐证据行右缘（`evRowRight - thumbs.right ≤ 6`）。
- **前往原文**：折叠态 `display:none`；展开态 `display:flex`、`font-size:11.5px`、与来源文本同排对齐。
- **交互**：点击缩略图固定（`data-cur` + `is-active` 联动）；悬停预览临时切图、移走恢复；键盘 Enter 固定；wheel（双指）/ pointer 拖拽滑动切图联动缩略图 `is-active`；点击缩略图**不**误触发手风琴展开；点击主图从激活索引打开 lightbox（`2/4`）、lightbox wheel 切图（`3/4`）、Esc 关闭。
- **可访问/降级**：reduced-motion 下主图与 lightbox wheel 切图瞬时；深/浅 × 1440/390 均无页面级水平滚动；无页面 JS 报错。
