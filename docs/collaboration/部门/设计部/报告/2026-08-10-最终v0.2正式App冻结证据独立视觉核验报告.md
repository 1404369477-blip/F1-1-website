## P2

### P2-01：六张证据的扩展名与实际媒体格式不一致

组件、视口和证据：`TASK-20260809-34476E-evidence/01…06-*.png`，覆盖 1440、1024、390 和深浅主题。六个文件均可解码，且 SHA 与 README 清单匹配；`file` 识别结果均为 JPEG/JFIF，README 和测试报告却反复把它们写为 PNG。

### P2-02：1440 档没有完整画面证据

组件、视口和证据：`01-1440x900-dark.png`、`02-1440x900-light.png`；实际像素为 1048×900 JPEG。README 记录 DOM `clientWidth=1440` 与导出工具归一，但两张图的右侧页面边界、完整桌面工具/设置区域和时间线卡片右缘不能由现有像素画面完整复核。

影响：1440 档的完整信息层级、桌面工具与设置关系不能由固定视觉证据独立验收。文字 DOM 收据不能代替完整截图。它与 P1-01 同为当前快照不可复用的表现，独立列为 P2 证据质量问题，避免重复扩大阻断数量。
