## 2. A · 移动端版面修正（index.html）

仅改设计草案 `index.html`（CSS + 交互 JS），未触碰 v0.2 token / 视觉语言基线（深浅主题、玻璃克制、trace 悬停浮现、reduced-motion / reduced-transparency、44px 触控、4px 图片硬边、focus-visible 3px 环）。

### 2.1 A1 · 标题/摘要信息块与主图同盒对齐
**根因**：`.tl-summary-btn` 用负 margin（桌面 `margin:-10px -8px -12px`、移动 `-8px -10px -10px`）把按钮盒左移以「出血」，但 `width:100%` 不随负 margin 增长，于是按钮盒与信息块内容盒相对 `.tl-media` 主图产生偏移（右缘差 20px、按钮盒窄 10px）。

**修订**：`.tl-summary-btn` 水平方向零 padding/margin，垂直方向保留外扩热区：
- 桌面：`padding:10px 0 12px; margin:-10px 0 -12px;`
- 移动（`@container` + `@media` 两块）：`padding:8px 0 10px; margin:-8px 0 -10px;`

**结果**（校验断言）：
- 移动 390：标题/摘要/主图/展开详情/证据行**同一水平盒** `17→373`（左右缘全一致）；主图左缘=标题左缘。
- 桌面 1440：标题/详情/证据行左缘全 `416`、右缘全 `1120` 一致；摘要受 `max-width:62ch`、主图受原始比例限制可更窄（设计语义，非错位）。
- 1024：同 1440，左缘 `148` 一致。

### 2.2 A2 · 日期/时间置于条目左上角
**根因**：移动 `.tl-time` 是满宽网格项（`grid-template-columns:1fr` 下 stretch 到 356px），`flex-direction:row-reverse` 把「日期+时刻」簇推到容器右缘 → 出现在条目**右上**。

**修订**：移动两块 `.tl-time` 增加 `justify-self:start;` —— 簇收缩为内容宽度并贴左缘；保留 `row-reverse`（日期在前/左、时刻在右）与 `align-items:baseline`（基线对齐）。

**结果**：日期 x=17（条目左缘）、时刻 x=67；簇顶=条目顶，落在**左上角**；深浅两态一致。

### 2.3 A3 · 展开后滚动定位到整条内容中央
**根因**：`setItemOpen` 用 `scrollIntoView({block:'start'})`，把展开条目顶钉在视口顶+20px，未把整条内容居中，时间上方留白观感差。

**修订**：改为手动居中滚动——展开动画结束后按「条目高度相对视口」计算：
```
gap = max(16, (viewportH - itemH) / 2)   // 条目高于视口时夹取下限 16px，保持时间/标题可见
top = max(0, pageYOffset + rect.top - gap)
window.scrollTo({ top, behavior: rm ? 'auto' : 'smooth' })  // reduced-motion 用 auto 且不延迟
```
**结果**（390 深/浅）：展开 r8 后条目中心 422 == 视口中心 422（垂直居中），timeTop=59px（上方留白适度，非大片空白）；reduced-motion 语义保持。

### 2.4 A4 · 390 整体回扫
- 无页面级水平滚动（`scrollWidth ≤ clientWidth`，390/1440/1024 全过）。
- 展开详情（`.tl-detail`）与证据行（`.tl-ev`）与信息块同一水平盒，中文提炼区块对齐。
- 时间簇并排（日期在前、时刻在后）baseline 对齐、簇顶对齐条目顶。
- 既有移动细节保持：缩略图 28px（`pointer:coarse` 抬升 40px）、主图限高 280px、触控目标 ≥44px、DRAFT 徽标隐藏、搜索 72px（focus 120px）。

## 3. B · 滑动翻页「一次滑动翻两张」根因与修复（index.html）

### 3.1 根因（三类，逐一对应修复）
| # | 根因 | 表现 | 修复 |
|---|---|---|---|
| ① | **pointer 与 wheel 双来源同手势触发**（触控板/混合设备同时发 pointer 与 wheel；touch 派生的 wheel 也被消费）。两来源各持独立冷却，无共享去重 | 一次手势 pointer 翻一张 + wheel 再翻一张 | **pointer 与 wheel 共享手势锁 `flipLockUntil`**（`FLIP_LOCK=400ms`）：任一来源翻页后锁定，同源或他源在锁期内一律不翻页 |
| ② | **wheel 慢速长滑二次累计**。旧 wheel 冷却只在「距上次翻页 350ms」内拦截；一次慢速双指滑切持续 >350ms 时事件继续累计再次越过阈值 | 一次慢速长滑翻两张 | wheel **连续手势内锁定 `wheelFlipLock` + 手势间隙 `WHEEL_GAP=100ms`**：事件间隔超 100ms 视为新手势并解锁累计；连续手势内翻页后锁定剩余事件直到手势停歇 |
| ③ | **`swiped` 标记无过期残留**。pointerup 后 click 本已用 `swiped` 抑制误开 lightbox，但 pointercancel / 无 click 场景下残留，之后正常轻点被误抑制（打不开 lightbox） | 滑动后下一次正常轻点失效 | `markSwiped()` **400ms 自动清除**：滑动量级拖拽无论是否翻页都记 swiped 且超时自动清除 |

### 3.2 修复实现
- **时间线主图 `bindMainSwipe`**：
  - 新增共享 `flipLockUntil`、wheel 手势状态（`wheelAcc/lastWheelAt/wheelFlipLock`）、`markSwiped()`（带 400ms 自动清除 + `pointerdown` 清除定时器）。
  - `endDrag`（pointer）：超阈值翻页前检查 `Date.now() >= flipLockUntil`，通过才翻页并锁定；滑动量级拖拽一律 `markSwiped()`。
  - wheel：非 ctrl、横向主导（`|deltaX|>|deltaY|`）才接管；事件间隔超 `WHEEL_GAP` 重置为新手势；`wheelFlipLock || now<flipLockUntil` 时忽略；翻页后置 `wheelFlipLock` + 锁并 `markSwiped()`。
- **lightbox `bindLightbox`**：同构应用 `lbFlipLockUntil`（400ms 共享锁）+ `lbWheelFlipLock`（连续手势锁定）+ `lbWheelAcc/lbWheelAt` 手势间隙；`endDrag` 翻页前查锁；滑动量级 `swiped=true` 抑制随后 click 误关。
- 方向/阈值判定不变：左滑→下一张、右滑→上一张；时间线主图阈值 `max(44, 0.12·w)`、lightbox 48px；纵向 wheel 放行页面滚动；`touch-action:pan-y` 保持。

### 3.3 验证（v0.2h PART2，390/1440 深色）
| 断言 | 结果 |
|---|---|
| 慢速连续 wheel（>400ms 长滑）→ 只翻一张 | ✅ |
| 等待锁期后第二次有意滑切仍可翻（连续意图仍生效） | ✅ |
| pointer 拖拽 → 只翻一张 | ✅ |
| pointer 拖拽 + 紧随 wheel（双来源同一手势）→ 只翻一张 | ✅ |
| 紧随滑动的 click → 不误开 lightbox（swiped 被消费） | ✅ |
| 纵向 wheel → 不翻页（放行页面滚动） | ✅ |
| 轻点主图（真实 tap）→ 正常打开 lightbox | ✅ |
| lightbox 内 pointer 拖拽 + 紧随 wheel → 只翻一张 | ✅ |
| lightbox 滑动后 click → 不误关 lightbox | ✅ |
