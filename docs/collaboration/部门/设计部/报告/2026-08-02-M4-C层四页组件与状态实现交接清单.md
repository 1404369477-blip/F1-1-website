## 1. 范围、路由权威与禁止事项

本清单把已经核收的全站设计规范、首批页面实现级设计合同和 token-map 转译成四页的组件、视图输入、状态、响应式、主题、无障碍和验收条目。它只增加实现检查记录，不增加页面、流程、领域状态或数据字段。

### 1.1 路由以 accepted Spec/ADR 为准

`route_hint` 只用于组织设计稿，不能作为产品路由真值。以下四路由来自 `docs/spec.md` §5、accepted ADR §3.1–3.2；实现时按此表注册页面。

| page_id | accepted 路由 | token-map/合同 route_hint | 访问边界 | 处理规则 |
|---|---|---|---|---|
| `public-feed` | `/` | `/` 或 `/feed` | 公开访客，只读 | 仅实现 `/`；`/feed` 不作为第二产品路由 |
| `content-detail` | `/stories/[publicId]` | `/story/:storyId` | 公开访客，只读；只引用本地公开投影 | 使用 `publicId`；`:storyId` 只是视觉组织提示 |
| `review-queue` | `/admin/reviews` | `/admin/review` | loopback local-dev admin；生产角色未知 | 仅实现 accepted 路径；不把生产认证当作已确认 |
| `source-management` | `/admin/sources` | `/admin/sources` | loopback local-dev admin；状态与阻断原因可见 | 保留 local-dev/loopback 边界 |

后台页面和 `/api/admin/*` 的实际访问门禁由 accepted ADR 的 loopback、Origin、会话和 CSRF 合同负责。本任务不改变权限、登录方案、跨网络访问或生产角色。

### 1.2 本任务不做

- 不改 `design/` 中已经冻结的规范、合同、token-map 或视觉样板。
- 不改 `app/`、`docs/spec.md`、任何 ADR、数据合同或业务状态机。
- 不安装 Appica UI、Base UI 或其他依赖；不引入其 `styles.css`。
- 不复制 Appica 演示页面或资产，不使用 F1、BMW/BMW M、Apple 商标、专有字体、官方摄影或无授权图片。
- 不接真实飞书、平台、AI、图片、发布或支付能力；只使用合成/脱敏 fixture。

## 3. 共同实现基座

### 3.1 `F1PageShell` 组合契约

四页共用下列结构；`F1PageShell` 是页面组合，不新增产品页面。

```text
F1PageShell
├─ F1TopBar
├─ F1DesktopNav / F1MobileMenu
├─ F1Main
│  ├─ F1PageHeader（公开页）或 F1AdminPageHeader（后台页）
│  └─ route content
└─ F1ToastViewport
```

建议的视图适配器输入（仅 UI 组合输入，不修改领域 schema）：

| 输入 | 作用 | 必须遵守 |
|---|---|---|
| `theme` | `dark`/`light` 主题上下文 | 默认深色；主题切换时 Portal/Drawer/Dialog 同步主题类 |
| `activeRoute` | 当前 accepted 路由 | 导航项使用 `aria-current="page"`；不从 route_hint 推断 |
| `navItems` | `brand`、`primaryNav`、搜索、主题、账户/菜单槽位 | 槽位与合同 §3.1 一致；菜单状态可读 |
| `pageHeader` | `eyebrow`、`title`、`description`、`actions` | 每页一个 H1；手机动作区纵向排列 |
| `content` | 当前 page adapter 的 DOM/组件树 | `main` 只出现一次；内容层使用实色表面 |
| `toastQueue` | 轻量反馈 | Toast 不代替页面级错误或审核决定 |
| `adminGuard` | local-dev guard 的只读结果 | 缺失 loopback/Origin/CSRF/session 时显示不可访问，不诱导创建或修改 |

验收：壳层在 320/390/768/1024/1200/1440/1600px 均保留顶部内容偏移；不出现页面级横向滚动；浮层和 Portal 不丢失主题。

## 4. 四页实现清单

### 4.1 公开信息流 `/`

来源：D-CONTRACT §4.1–§4.6；D-TOKEN `pages.public-feed`（`layout`、`components`、`states`、`a11y`）。

#### 组件树与视图输入

```text
F1PageShell
├─ F1TopBar
├─ F1PageHeader
├─ F1FeaturedStory（最多 1 个主头条 + 最多 2 个次级内容）
├─ F1FilterBar
│  └─ F1FilterDrawer（手机）
├─ F1StoryGrid
│  └─ F1StoryCard[]
├─ F1StatusBadge / F1SourceMeta
├─ F1SkeletonCard / F1EmptyState / F1ErrorState / F1NoMore
└─ F1ToastViewport
```

视图适配器只读已有内容投影/fixture：`items[]`（`publicId`、中文标题、摘要、分类/内容类型、来源/作者、`published_at`、`captured_at` 或更新时间、内容状态、`external_url`/原文入口、`media`、`alt`/署名/授权状态）、`filters`、`pageState`、失败来源摘要和新增数量。不存在的字段显示“未知/未核验”，不自行推导。

#### 状态与动作清单

| 状态 | 必须呈现 | 可用动作／限制 | 交接勾选 |
|---|---|---|---|
| `loading` | 头条与卡片按最终比例的 Skeleton | 无；布局不跳动 | [ ] |
| `empty` | 原因、当前筛选、清除筛选 | `clear-filters`；无权限时不诱导创建 | [ ] |
| `error` | 发生位置、可理解原因、错误编号（如有） | `retry`；页面保留回退出口 | [ ] |
| `partial` | 已加载数量、失败来源/项目入口 | `view-failures` 或继续阅读；不能只报成功 | [ ] |
| `offline/restricted` | 最近可用内容、更新时间、受限原因 | `retry`；不伪造实时状态 | [ ] |
| `no-more` | 明确“已无更多内容” | 不继续显示加载动画 | [ ] |
| `live-refresh` | 不抢焦点的新增提示条 | `view-new`；`aria-live="polite"` | [ ] |

#### 响应式与媒体

- 320/390px：4 列基础网格，主头条图片在上、文字在下，StoryGrid 1 列；筛选进入可关闭 Drawer，Chip 保留已选条件。
- 768/1024px：8 列，主头条 5 列+次级 3 列，StoryGrid 2 列；筛选可换行。
- 1200/1440/1600px：12 列，主头条 8+4、StoryGrid 3 列、24px 沟槽；容器最大 1440px。
- 头条使用 16:7/16:9（桌面/平板），手机 4:5/3:4；常规卡片桌面 3:2、手机 16:9；缺图、无授权、加载失败使用中性占位+来源/原文入口+显式“缺图/未核验”，不拉伸、不伪造摄影。

#### 无障碍实现点

- `main` 包含唯一主内容；信息流使用 `section`+`ul`（或等价列表），每卡有可读标题。
- 图片 `alt` 描述实际内容；装饰点阵/渐变 `aria-hidden="true"`；媒体说明、署名、授权状态关联。
- 筛选按钮名称和选中状态可读；Drawer 打开后焦点留在面板内，关闭回到触发点。
- 刷新、清除筛选、主题切换、卡片内部原文链接均可键盘完成；新增提示不抢焦点。

### 4.2 内容详情 `/stories/[publicId]`

来源：D-CONTRACT §5.1–§5.6；D-TOKEN `pages.content-detail`（`layout`、`components`、`states`、`a11y`）。

#### 组件树与视图输入

```text
F1PageShell
├─ F1Breadcrumb
├─ F1ArticleMeta / F1ArticleHeader
├─ F1LeadMedia
├─ F1ArticleBody
├─ F1KeyFacts
├─ F1SourceEvidence + F1ExternalLink
├─ F1CorrectionBanner（需要时）
├─ F1RelatedStoryList
└─ F1SkeletonArticle / F1ErrorState / F1NotFoundState
```

视图输入：`publicId`、中文标题/导语/正文、分类、来源/作者、发布时间/更新时间、`content_version`、原始来源证据、`external_url`、`media`（含比例、`alt`、caption、署名、授权状态）、内容状态、修订/更正说明和相关 `publicId[]`。`SourceEvidence` 只展示脱敏可公开字段；不输出原始平台包、提示词、凭证、内部堆栈或私密 URL。

#### 状态与动作清单

| 状态 | 必须呈现 | 可用动作／限制 | 交接勾选 |
|---|---|---|---|
| `loading` | 标题、媒体、正文骨架保持最终比例 | 无 | [ ] |
| `not-found` | 内容不存在/已下架说明 | `back-to-feed` | [ ] |
| `error` | 位置、原因、重试/返回出口 | `retry` | [ ] |
| `withdrawn` | 撤回说明和必要更正信息 | `back-to-feed`；不渲染为正常内容 | [ ] |
| `media-missing` | 中性无图占位、来源信息、缺图说明 | `open-source` | [ ] |
| `source-restricted` | 原文受限说明；不伪造可读正文 | `open-source` | [ ] |
| `correction` | 更正标记、更新时间、新旧版本说明 | `view-source`；原文入口可见 | [ ] |

#### 响应式与可访问性

- 桌面：正文最大 680px，媒体最大 960px；证据右侧 4 列或正文下折叠；正文不使用玻璃。
- 平板：正文 5 列+证据 3 列，媒体跨 8 列。
- 手机：标题→导语→媒体→正文→证据单列；证据可折叠，但原文入口始终可发现；分享/收藏工具不遮挡正文。
- 使用 `main`、`article`、`header`、`aside`、`nav`；Breadcrumb 当前项 `aria-current="page"`；标题层级连续；来源链接有明确文字，不只放图标；媒体 caption/署名/授权与媒体程序化关联。

| `pending-review` | 草稿、证据、媒体、版本信息 | `save-draft`、`approve`、`reject` | [ ] |
