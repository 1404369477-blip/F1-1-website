## 1. 当前 app 实现 review（问题定位）

review 对象：`app/src/features/stories/feed-experience.tsx`（媒体区渲染 + lightbox 交互）、`app/src/app/globals.css`（`.ph-main/.ph-thumbs/.ph-thumb/.lightbox`）、以及当前草案 `index.html`（v0.2c 相册式轮播版）。对照用户 6 项新需求，现状差距：

### 1.1 媒体区是「相册式轮播」，用户要「单张主图 + 右下角小缩略图」
- **草案（v0.2c）与 app 当前**都是轮播/主图+右侧竖向缩略图结构：草案 v0.2c 为居中主图 + 两侧灰度/低对比裁切预览 + 滑动吸入切图；app 为「主图 + 右侧竖向缩略图列」。用户新方向要求**只显示单张主图**，缩略图**缩小、叠放在主图右下角**——这是布局级替换。
- 需求②的「缩略图缩小、叠放主图右下角」与当前「右侧竖向缩略图列」（app 80px/56px）或「两侧大卡预览」（v0.2c）都不同，需重新定位。

### 1.2 前往原文的位置
- 当前草案与 app 的「前往原文 ↗」都在条目底部**证据行**（`.tl-ev`）右侧，折叠与展开都显示。用户要求**折叠时不显示、展开后出现在详情区**——需从证据行移到展开详情内。

### 1.3 缩略图在展开详情后的位置不变
- app 与草案的媒体区在 `.tl-summary-btn` 之后、`.tl-collapse`（展开区）之前，独立于展开区。只要缩略图叠层相对媒体区（主图）绝对定位，展开时即天然固定不动；需保证叠层锚定主图本身而非整列容器。

### 1.4 契约仍未固化新方向
- `F1+1-v0.2-实现级设计合同.md` §2.3/§3/§4.7/§5 仍是「主图限高 255px / 缩略图 40px / **左下方**缩略图导航 / 前往原文在证据行」。本任务不修改该契约（实现级基线），差异记入 §4 待同步。

## 2. 修订设计决策与理由

仅改设计草案 `design/ui/F1+1-v0.2-全站设计/index.html`（CSS + 模板 + 交互 JS），未触碰 v0.2 token/视觉语言基线（深浅主题、玻璃克制、trace 悬停浮现、reduced-motion/reduced-transparency 降级、44px 触控、4px 图片硬边、focus-visible 3px 环）。

### 2.1 单张主图（媒体区核心）
| 项 | 值 | 依据 |
|---|---|---|
| 结构 | `.tl-media` 内**仅一张** `.ph-main`（多图时附加 `.ph-thumbs` 叠层） | 需求①：只显示单张主图，取消两侧灰度预览/滑切 |
| 主图策略 | 原比例、`max-width:100%` + **限高 360px**（移动 280px）、`object-fit` 默认（整图缩放**不裁切**）、4px 圆角、柔和投影 | 需求①「主图保持放大」：沿用 v0.2b/c 的限高「合理值」（较契约 255px 放大）；对齐 v0.1「新闻图片 4px 硬边」 |
| `.tl-media` | `display:block; width:fit-content; max-width:100%; position:relative` | 让媒体区**收缩到主图实际宽度**，右下角叠层即可锚定主图右下角，而非整列容器 |
| 点击 | 主图点击/Enter/Space → 从**当前激活索引**（`data-idx`）打开 lightbox | 与 pinned/悬停预览保持一致 |

### 2.2 右下角小缩略图（叠层）
| 项 | 值 | 依据 |
|---|---|---|
| 叠层容器 `.ph-thumbs` | `position:absolute; right:8px; bottom:8px`（移动 `6px`）；`display:flex; gap:6px`（移动 4px）；`padding:6px`（移动 5px）；圆角 6px；`rgba(0,0,0,.45)` 底 + `rgba(255,255,255,.18)` 描边 + `blur(8px) saturate(160%)` + 投影 | 需求②「相对主图定位、叠放主图右下角」；半透明底/描边保证在任意照片上可辨识 |
| 缩略图 `.ph-thumb` | **高 40px**（桌面）/ **32px**（移动）/ 44px（`pointer:coarse`），`width:auto`（保持比例、不裁切）、4px 圆角、`opacity:.6` | 需求②「缩略图缩小」：相对 v0.2b 右侧 88px 竖向列明显缩小；不裁切避免丢失信息 |
| 激活态 | `opacity:1` + `--accent` 1.5px 描边（`aria-pressed/aria-current` 同步） | 明确当前主图来源 |
| 悬停 | `opacity:1` + `scale(1.06)`（150ms 沿用 reveal 节奏） | 悬停预览保留（需求②） |
| 触控命中 | 叠层 padding 6px + 缩略图高 ≥ 44px（桌面 40+12=52、移动 32+12=44、coarse 44+12=56） | 契约 §6.4「缩略图命中区 ≥44px」由叠层整体满足 |
| 交互 | 悬停 → 主图**临时预览**；移走 → 恢复当前固定图；点击/Enter/Space → **固定切换**（更新 `data-cur` + 主图 `src/alt/data-idx` + 激活缩略图） | 需求②「点击切换主图、悬停预览保留」 |
| 单图内容 | `imgs.length === 1` 不渲染 `.ph-thumbs` | 与契约 §4.3 一致 |

### 2.3 前往原文移入展开详情
| 项 | 值 | 依据 |
|---|---|---|
| 位置 | `.tl-original` 放在 `.tl-detail`（展开区）**中文提炼末尾** | 需求③「移入展开详情区」；折叠时 `.tl-collapse` 为 `grid-template-rows:0fr` + `overflow:hidden`，链接被裁切**不显示**；展开后出现 |
| 样式 | `--accent` 文本链接 + ↗、`min-height:44px`、hover 下划线 | 与 v0.2「一个动作、一个主路径」一致；44px 触控 |
| 证据行 `.tl-ev` | 只保留 `信源 · 作者 · 时间`（11.5px faint），折叠/展开均显示 | 需求③只把**前往原文**移走，证据行保留 |

### 2.4 展开后缩略图相对主图不变
- 缩略图叠层 `.ph-thumbs` 绝对定位在 `.tl-media` 内，`.tl-media` 位于 `.tl-collapse`（展开区）**之前**、独立于展开动画；展开/收起只改 `.tl-collapse` 的 `grid-template-rows`，不影响媒体区布局。
- 已用断言验证：折叠态与展开态下，缩略图叠层相对主图的偏移（`dx = chip.left - main.left`，`dy = main.bottom - chip.bottom`）**完全一致**（6 组合全过）。

### 2.5 lightbox（保留滑动自然切图）
- 保留 v0.2c 的**自然切图**：拖动跟随（`translateX(dx)`）→ 超阈值（48px，横向主导）当前图滑出（210ms）→ 换图 → 下一张从对侧滑入（250ms），`cubic-bezier(.2,.6,.2,1)`；低于阈值回弹。
- 保留：Esc / 点击背景关闭 / `ArrowLeft/Right` / ‹› 按钮 / `N / M` 计数 / `role="dialog" aria-modal` / 打开焦点进、关闭焦点返回触发主图 / reduced-motion 瞬时切换。
- 图集来源改为当前媒体区的 `.ph-thumb`（多图）或 `.ph-main`（单图）；从主图打开时以 `data-idx`（当前激活索引）定位初始图，与 pinned/悬停一致。

### 2.6 与 v0.2 视觉语言的保持
- 深浅主题：叠层在双主题下一致（深色半透明底 + 白描边，适用于任意照片）。
- 降级：`prefers-reduced-transparency` → 叠层转**不透明**深底（`rgba(0,0,0,.78)`、`backdrop-filter:none`）；`prefers-reduced-motion` → 全局 `.01ms` 过渡 + JS `rm()` 跳过，切图/预览瞬时。
- 键盘：主图 Enter/Space 放大；缩略图 Enter/Space 固定；lightbox Esc/方向键；focus-visible 3px 环不变。
- 44px 触控：主图命中区远大于 44px；缩略图叠层 ≥44px；前往原文 44px；lightbox 翻页按钮 48px。
