## 2. 修订设计决策与理由

仅改设计草案 `index.html`（CSS token + 第 9 节组件样式 + HTML 结构 + 交互 JS），未触碰 v0.2 视觉语言基线（深浅主题、玻璃克制仅保留在面板 / toast、trace 悬停浮现、reduced-motion / reduced-transparency、44px 触控、focus-visible 3px 环）。

### 2.1 无外框纯文字：视觉只保留「文字 + 一点阴影」
| 项 | 值 | 依据 |
|---|---|---|
| 移除外框 | `.fab` 去掉 `.glass`；`background:transparent`、`border:0`、`border-radius:0` | 需求①「不要带外框」；玻璃克制原则把毛玻璃只留给悬浮面板与 toast |
| 直接文字 | 12.5px / weight 600，`color: var(--muted)` | 需求②「直接文字」；与顶栏搜索等 trace 控件同字号梯队，低调不喧宾 |
| 一点阴影 | 新增 `--ts-1` text-shadow token（深色 `0 1px 2px oklch(0 0 0/.55), 0 2px 8px oklch(0 0 0/.32)`；浅色 `0 1px 1px oklch(0 0 0/.20), 0 2px 6px oklch(0 0 0/.12)`） | 需求②「一点阴影」：让半透明文字在实色/图片背景上始终可辨，替代胶囊的分层作用，且无视觉框 |
| 可访问对比 | 隐形态为 trace 基线（.5 + muted）；hover/focus 浮现为 accent 全对比 | 正文/证据链不受低对比影响，功能控件走悬停浮现 |

### 2.2 右下角堆叠：设置锚定角落，回到顶部叠于其上方
| 项 | 值 | 依据 |
|---|---|---|
| 设置 | `position:fixed; right:16px; bottom:16px`（角落锚点） | 设置是持续存在的功能入口，锚定右下角最顺手的角落 |
| 回到顶部 | `right:16px; bottom:60px`（叠于设置上方） | 需求「右下角堆叠（回到顶部在上或下按合理布局）」；回到顶部属工具类功能，置于更角落的操作（设置）之上，视觉从上到下为「回到顶部 → 设置」 |
| 命中区 | 两者 `min-width/min-height:44px`，视觉无框但点击区完整 | 需求「44px 命中区可保留但视觉无框」 |
| 设置面板 | `bottom: calc(16px + 44px + 44px + 8px)` = 112px，右对齐 `right:16px` | 面板为唯一玻璃浮层，上移避开两按钮，打开不遮挡 |
| 间距观感 | 两按钮 44px 命中区相叠、文字按各自命中区垂直居中，纵向留出清晰间隔 | 隐形文字控件刻意留白；触屏无 hover 时按钮各自 44px 可点，无重叠误触 |

### 2.3 隐形呈现 + 悬停/焦点高亮（复用 trace 悬停浮现）
| 层级 | 状态 | 实现 |
|---|---|---|
| 默认隐形 | 两按钮 `.trace` 基线 | `opacity:.5` + muted 色 + text-shadow，低调常驻 |
| 悬停高亮 | `.trace:hover` | `opacity:1` + `scale(1.04)` + `color:var(--accent)`，150ms ease-out |
| 键盘聚焦 | `.trace:focus-visible` | 同样全对比 + 微放大；另有全局 3px `--focus` 焦点环，键盘可达 |
| 触屏降级 | `@media (pointer: coarse)` | 基准对比提升 `.85`，避免不可发现 |
| 减少动效 | `prefers-reduced-motion` / `[data-rm]` | 取消 scale，只保留对比度/可见度变化 |
| 证据/调试 | `#reveal=1` | 全部 trace 强制显形，便于导出 |

### 2.4 新增回到顶部交互
- 点击 `#back-to-top` → `window.scrollTo({top:0, behavior: reduced-motion ? 'auto' : 'smooth'})`，尊重 `prefers-reduced-motion` / `[data-rm]`（瞬时回顶）。
- 草案阶段**始终常驻右下角**（以低透明度隐形），未做「滚动到页首即隐藏」门控——该门控为可选增强，留待用户确认（见 §5）。

### 2.5 与已确认布局的取舍
- **不推翻**：单主图 + 右下角缩略图、前往原文行内化、滑动切图（pointer + wheel）、lightbox、就地展开、深浅主题、trace、44px 触控、reduced-motion / reduced-transparency 全部保持。
- 本次仅改动右下角悬浮控件本体（设置 FAB 样式）与新增固定回到顶部按钮；设置面板仅随之下移/上移到不遮挡的位置，面板内容（主题 / 宽度 / 状态 / 降级）不变。

### 3.2 CSS（第 9 节）

- `.draft-panel` 底部从 76px 上移至 `calc(16px + 44px + 44px + 8px)`、`right:16px`，保持 `glass`（唯一玻璃浮层）。

### 3.3 HTML
- `#fab` 移除 `glass` 类，仅保留 `trace`。
- 新增 `<button class="back-to-top trace" id="back-to-top">↑ 回到顶部</button>`（置于 `#fab` 之前）。
- `#draft-panel` 结构不变。

### 3.4 交互（JS）
- `bindPanel` 新增回到顶部点击处理：`prefersReducedMotion()` 判定后 `scrollTo({top:0, behavior})`。
- 其余（面板开关、aria-expanded、主题/宽度/状态/降级）不变。

### 4.1 关键断言（81/81 全过，按面分组）
- **无外框**：两按钮 `background:transparent`、`border-width:0`、`border-radius:0`、`#fab` 无 `.glass` 类。
- **纯文字 + 阴影**：`text-shadow` 均非 `none`（深浅两套 `--ts-1` 生效）。
- **右下角堆叠**：`fab` `right:16/bottom:16`、`back-to-top` `right:16/bottom:60`、两者命中区 `44×44`、无重叠（`backToTop.rect.y+h <= fab.rect.y`）。
- **默认隐形 / 悬停高亮**：默认 `opacity=.5`；hover 回到顶部 → `opacity:1` + accent 色 + `scale(1.04)`（`matrix(1.04,…)`），hover 时另一按钮保持 `.5`；hover 设置同理。
- **键盘可达**：`#back-to-top.focus()` 后 `:focus-visible` 命中、等待过渡完成后 `opacity:1` + accent 色。
- **面板**：打开后仍为 `.glass`、`bottom` 位于两按钮之上（不遮挡）。
- **降级**：`reduced-motion` 下 hover 取消放大（`transform:none`）但对比度浮现保留、回到顶部瞬时滚动；普通模式回到顶部可平滑回页首且无 JS 报错。
- **布局保持**：深浅 × 1440/390 均无页面级水平滚动、无页面 JS 报错；像素复核确认深色默认态为暗淡灰字、悬停态出现 accent 蓝像素。

**未验证（交用户 / 测试部）：**
- **真实设备手感**：Playwright 无头仅为近似；移动端 44px 命中区、`pointer:coarse` 下 `.85` 可视度、右下角两按钮堆叠在 iOS / Android 实机上的可发现性与误触待实测。

- **回到顶部常驻 vs 滚动门控**：草案让回到顶部始终常驻（低透明度隐形）；若用户希望「仅在向下滚动后出现」，可后续加滚动门控，属可选增强，未擅自加入。
- **设置面板打开时机**：面板现上移至两按钮上方打开；打开时是否隐藏回到顶部、或保持现位置待用户确认。
