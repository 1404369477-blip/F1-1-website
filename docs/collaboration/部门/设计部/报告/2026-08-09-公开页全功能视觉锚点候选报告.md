## 2. 用户反馈后的修正

首版候选采用了独立视觉外壳，虽然覆盖了功能状态，但顶栏、首屏信息密度、时间轴和媒体几何未严格继承最新冻结稿。用户在小窗口中指出该偏差后，设计部执行以下修正：

1. 撤回首版独立视觉外壳；其浏览器记录作废，不计入当前证据。
2. 用 `F1+1-v0.2-final-20260808.html` 的逐字节副本覆盖候选，再仅在候选副本中增加分类、分页、0 图、七类 feed 状态、行内详情错误与独立详情状态。
3. 重新按冻结 CSS 回读几何：主媒体保持原始比例并限高 360/280px，时间轴保持 `64px + 32px` 网格，缩略图保持 32/22px，移动端保持冻结单列与 Dock；不再使用首版外壳的几何描述。
4. 重新生成实现映射和 SHA 清单。
