## 0. 总评

这是一套**方向真实、纪律罕见**的设计：它把「F1 资讯站」的论点落在时间本身（计时塔语汇的编辑化转译），而不是落在模板化的 hero 大卡上；结构件全部编码真实信息；唯一的大胆手势（展开聚焦灰度退晕）恰好解决了真实新闻照片调色板互相打架的难题。按 frontend-design 透镜的校准，配色落在 AI 默认簇（近黑+单一蓝色 accent），但品牌简报明确冻结了深色方向——**按 skill 规则「简报的话永远赢」，合规**；使其不读作模板的是结构而非配色。

需要正视的是三类问题，全部**不涉及方向否定**：①制品与其自有规范文档在五处互相矛盾（开发硬门锚定冻结身份时，文档数字与冻结渲染不一致会成为实现歧义源）；②自设的 44px 触控地板被自家制品在触屏端打破；③若干可见错误/陈旧文案已被冻进用户确认过的制品，而发布视频正要用这份制品出素材。全部改动建议走设计部/统筹 TASK 流程，本报告不代行。

## 1. 强项（透镜正面确认，应予保留）

- **S1 ·「hero 即论点」成立**。打开页面即「最新资讯 + 发布时间」，时间线本身就是 F1 世界最具特征之物的转译。没有用大数字+渐变大卡的模板答案。✔ skill「hero is a thesis」
- **S2 · 结构即信息**。发丝轴 + 左列时间编码真实时序；分类眉题（车手/新闻）、证据行（信源·时间）都是真元数据；无装饰性 01/02/03 编号。✔ skill「structure is information」满分项
- **S3 · 大胆只花在一个地方**。展开聚焦（`#tl.is-focusing`：其余条目 opacity .38 + grayscale .85，index.html:350-355）+ lightbox 全彩隔离是唯一签名手势；它同时是功能（注意力编码）与美学（休止态全彩、聚焦态唯焦点全彩，天然中和了红帽/绿车/橙衣的调色板冲突）。1440 展开态截图确认该行为戏剧化且有效。✔ skill「spend your boldness in one place」
- **S4 · 动效成体系且克制**。140/240/340ms 三档、单一缓动、reduced-motion 全链尊重（含 lightbox 与展开箭头）；是编排过的时刻而非散点特效。
- **S5 · 质量地板存在且未自我标榜**。390 断点不是挤压而是重排（日期/时刻并排日期在前、轴与节点隐藏——实测与 spec §5 一致）；焦点环、双主题完整；`.tl-summary-btn` 用负 margin 外扩热区（index.html:308-311）是成熟的触控补偿手法。
- **S6 · 悬停浮现（.trace）体系一致**。低对比常驻 → hover/focus 浮现（1 + scale 1.04），触屏基准提到 .85；正文/日期/证据不受低对比影响——渐进披露的边界划得正确。

## 2. 发现清单

> 每条标注**冻结关系**：`规范漂移`（制品与自有文档矛盾）/ `刻意偏离`（制品注释自述有意为之但文档未同步）/ `陈旧错误`（冻进制品的错）/ `设计缺口`（真实内容暴露的下一迭代问题）/ `风险`（待验证）。

### A. 制品与自有规范文档漂移（5 处）——最 consequential 的一类

开发硬门把实现锚到「冻结设计的版本+路径+SHA-256」，而设计部交付物中的文档数字与冻结渲染不一致；实现方无论照哪边都会偏离另一边。

| # | 发现 | 证据 | 冻结关系 |
| --- | --- | --- | --- |
| A1 | **标题未用 Display 字体**：`.tl-title` 无 `font-family`（index.html:358-363），CDP 实测 computed = `Inter, …` 栈；对照组 `.tl-d` 日期正确使用 `var(--font-display)`（index.html:295-301）。`design-system.md` §2.2：「Display（标题/日期/状态码）：Barlow Condensed」。影响面：中文标题无视觉差（CJK 回退相同），但标题中的拉丁字符/数字（F1、2026…）落入 Inter，丢掉 condensed 编辑面孔；brand-spec「BMW M 三点」之「标题字重」部分落空 | 代码 + CDP 实测 | **规范漂移** |
| A2 | **列宽**：`.app max-width 880px`、padding `clamp(16px,3.5vw,40px)`（index.html:154-161）→ 1440 下内容列按 CSS 推算约 800px；`design-system.md` §1/§3/§5 三处写「单列 max **920px**」 | 代码推算 | **规范漂移** |
| A3 | **主图限高**：`.ph-main max-height: 360px`（index.html:385-389）、移动断点 280px（:783）；`design-system.md` §2.3「限高 **255px**」 | 代码 | **规范漂移** |
| A4 | **缩略图高度**：CDP 实测 @390 = **32×22px**；`design-system.md` §2.3「高 40px（移动端 32px）」。制品注释自述 v0.2k 为保单行证据行刻意收紧（index.html:786-789） | CDP 实测 + 注释 | **刻意偏离，文档未同步** |
| A5 | **摘要截断**：r1 @390 实测 3 行完整显示；v0.2j 注释自述「移除 -webkit-line-clamp 截断，完整显示不省略」（index.html:369-370）；`design-system.md` §3 仍写「摘要钳 2 行」 | CDP 实测 + 注释 | **刻意偏离，文档未同步** |

→ 裁定权在设计部：若冻结渲染为真值（用户确认的是渲染结果），则 `design-system.md` 与 token-map 需同步修正；反之则需改制品并重新冻结。**两边不动=把矛盾传给开发部**，而硬门禁止开发部自行猜测（视觉缺口回退条款）。

## 3. AI-default 校准（skill 要求的如实标注）

近黑底 + 单一蓝色 accent 落在 skill 标注的 AI 默认簇 (2)。但：`brand-spec.md` 明确冻结「默认深色 + 交互蓝」，按 skill 自身规则「**简报钉死方向时，简报的话永远赢，包括它要求默认簇之一**」——判定合规，非扣分项。真正使其区别于模板的是：condensed display 数字（计时塔语汇）、发丝轴、灰度聚焦手势。如实建议：若 v0.3 重开颜色轴，差异化不会来自调色板，不必在配色上追加投入。

## 4. 与发布视频（launch video）的时序耦合

发布视频素材规则绑定**本制品当前 hash**（5a84bf…）真实截图。但本报告 C1（7 条示例）、C2（页脚声明）、F1（meta）会被录进成片；A/B 类若勘误也会改 hash。存在明确的时序决策点：**先勘误再录制**（推荐，勘误 TASK 量小），或**明确用旧 hash 录制、勘误进下一版**（需接受成片携带 C1/C2）。这是统筹/用户的决策，本报告只揭示张力。

## 5. 建议路由（本会话不建 TASK，供统筹部/用户定夺）

候选派单「v0.2 冻结制品勘误与裁定」（建议设计部主导、统筹派单、测试部复验）：

1. **裁定 A1–A5 唯一真值**并同步 `design-system.md` / token-map（或改制品重新冻结）；
