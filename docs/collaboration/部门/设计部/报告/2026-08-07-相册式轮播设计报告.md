## 1. 当前 app 实现 review（问题定位）

review 对象：`app/src/features/stories/feed-experience.tsx`（媒体区渲染 + lightbox 交互）、`app/src/app/globals.css`（`.ph-main/.ph-thumbs/.ph-thumb/.lightbox`）。对照用户 5 项新需求，现状差距：

### 1.1 布局是「主图 + 右侧竖向缩略图」，无居中主图、无两侧预览
- **设计草案**（v0.2b）与 **app** 当前都是 `主图左 + 右侧竖向缩略图列`（草案 88px/移动 64px 右列；app 80px/56px）。用户新方向要的是**居中主图 + 两侧灰度/低对比裁切预览**——这是布局级的替换，不是增量调整。
- 无任何「滑动切图 / 吸入转原彩」能力：app 与草案的缩略图交互是「悬停预览 / 点击固定」，与相册式滑动手势冲突。

### 1.2 图片策略「不裁切」与需求「允许裁切」冲突
- v0.2b 主图为 `整图缩放不裁切`（限高 360px）；需求②明确「其他图片在两侧……**允许有裁切**」。两侧预览需要 `object-fit: cover` + 舞台横向裁切。

### 1.3 lightbox 只有淡入淡出切图，非「自然切图」
- app 与草案 lightbox 翻页都是 `opacity` 淡入淡出；需求④要求「滑动翻页、**自然切图**，与苹果系统交互体验一致」。需要滑动跟随 + 滑出/滑入过渡。

### 1.4 契约未固化相册式方向
- `F1+1-v0.2-实现级设计合同.md` §2.3/§3/§5 仍是「主图限高 255px / 缩略图 40px / 左下方缩略图导航」。本任务不修改该契约（实现级基线），记入 §4 待同步。

## 2. 修订设计决策与理由

仅改设计草案 `design/ui/F1+1-v0.2-全站设计/index.html`（CSS + 模板 + 轮播/lightbox JS），未触碰 v0.2 token/视觉语言基线（深浅主题、玻璃克制、trace 悬停浮现、reduced-motion/reduced-transparency 降级、44px 触控、4px 图片硬边、focus-visible 3px 环）。

### 2.1 轮播舞台与卡片尺寸
| 项 | 值 | 依据 |
|---|---|---|
| 舞台高（桌面） | `clamp(240px, 38cqw, 320px)`；实测 1440→**304px**、1024→**320px**（shell 宽度差异） | 38cqw 随 `.app` 容器缩放，桌面统一落在一档，避免 vw 造成 1024/1440 不一致 |
| 舞台高（移动 390） | **200px**（`@container`/`@media` 双兜底） | 移动宽度才是约束，高度服务竖/方图 |
| 卡片宽 | **76%** 舞台宽（实测 1440→535px、1024→626px、390→271px） | 居中留出两侧 12% 给预览露出 |
| 卡片间距 | 12px | 与 v0.2 间距节奏一致，视觉上「相册卡片并排」 |
| 舞台圆角 | `--r-md` 10px；卡片圆角 4px | 对齐 v0.1「新闻图片 4px 硬边」 |
| 居中主图 | `object-fit: cover`、`filter:none`、`opacity:1`、增强投影 | 高亮原彩（需求①）；cover 保证整卡统一、桌面 16:9 几乎无裁切 |
| 两侧预览 | `object-fit: cover`，`filter: grayscale(1) contrast(.7) brightness(.85)`，`opacity:.5`，被舞台边缘裁切 | 需求②灰度 + 低对比 + 允许裁切；露出条约 **8–10%** 舞台宽（实测 1440≈73px、390≈31px） |
| 超出两侧 | `opacity:0` + `aria-hidden="true"` + `pointer-events:none` | 只渲染「上一张 / 下一张」两个预览，其余不可见 |

### 2.2 灰度/低对比参数
- 居中（rel=0）：`filter:none`、`opacity:1`。
- 相邻（rel=±1）：`grayscale(1) contrast(.7) brightness(.85)`、`opacity:.5`（触屏 coarse 基准可提至 `.7`）。
- 中间过渡：`grayscale/contrast/brightness/opacity` 按 `|rel|` 在 0→1 线性插值（拖动时连续渐变，松手后过渡到整数档）。
- 对比度说明：预览属于**装饰性裁切**（非文本、非信息载体），灰度低对比不承担 WCAG 文本对比义务；居中主图始终全彩高对比。

### 2.3 滑动切图（相册式「吸入」）
- 手势：`pointerdown/move/up/cancel`（触摸 + 鼠标左键），舞台 `touch-action: pan-y`（横向交 JS、纵向仍可滚）。
- 跟随：拖动期间给舞台加 `.is-dragging` → 关闭卡片过渡（`transition:none`），卡片跟随手指 1:1 位移，两侧灰度随位移连续渐变。
- 阈值：`max(48px, 16% × 舞台宽)` 且 `|dx|>|dy|`（横向主导）才切图；低于阈值**回弹原位**。
- 方向：**左滑下一张 / 右滑上一张**。
- 切图过渡：`transform/filter/opacity` 300ms `cubic-bezier(.22,.72,.24,1.02)`（带轻微回弹的「吸入」感，新增 `--car-swap/--car-ease` 局部 token，不改全局 `--t-*`）。
- 边界：轮播**两端不循环**——拖到首/末向外拖有 0.32× 阻力，松手回弹；首/末只露出一侧预览，直观传达边界（lightbox 仍循环）。
- 点击两侧预览 → 直接切到居中（`carGoTo`）；点击居中主图 → 打开 lightbox。
- reduced-motion：全局 `.01ms` 过渡 + JS `rm()` 跳过，切图瞬时（不吸入动画）。

### 2.4 内嵌控件与键盘
- ‹ › 按钮：44px、`.trace` 低对比常驻、hover/focus 浮现、位于两端中点；**边界处 `disabled`**（首禁「上」、末禁「下」，降低到 `.3`）。
- 计数：右下角小胶囊 `N / M`，`aria-live="polite"`、`tabular-nums`，`reduced-transparency` 时加深底。
- 键盘：`.car-stage` `tabindex="0"` + `role="group"` + `aria-roledescription="轮播"`；聚焦舞台时 `ArrowLeft/Right` 切图、`Enter/Space` 打开 lightbox；关闭后焦点返回触发卡片。

### 2.5 lightbox 自然切图
- 打开：从触发卡片位置缩放放大居中全彩（340ms，沿用）。
- **滑动切图**：拖动跟随（`translateX(dx)`）→ 超阈值（48px，横向主导）`slideSwap(delta)`：当前图滑出（210ms）→ 换图 → 下一张从对侧滑入（250ms），`cubic-bezier(.2,.6,.2,1)`；低于阈值回弹。
- 触发：‹› 按钮 / `ArrowLeft/Right` / 滑动，全部走同一 `slideSwap`。
- 保留：`Esc` / 点击背景关闭 / `N / M` 计数 / `role="dialog" aria-modal` / 打开焦点进、关闭焦点回触发点 / `reduced-motion` 瞬时切换。
- 循环：lightbox 序号取模回绕（苹果相册行为）。

### 2.6 单图内容
- `imgs.length === 1`：不进入轮播，沿用 `.ph-main`（整图缩放不裁切、限高 360px 桌面 / 280px 移动），可点击放大。与 v0.2 单图策略一致。

### 2.7 与 v0.2 视觉语言的保持
- 深浅主题：轮播在 `data-theme` 双主题下完整可用；`car-count`/`car-nav` 用半透明深底 + 白字，深浅主题一致可读。
- 降级：`prefers-reduced-transparency` → 玻璃 chip/按钮回退不透明；`prefers-reduced-motion` → 切图瞬时、无缩放位移；低性能端 blur 8px。
- 44px 触控：‹› 按钮、lightbox 按钮均 ≥44px；卡片本身命中区远大于 44px。
