## 2. 修订设计决策与理由

仅改设计草案 `index.html`（token + 第 9 节样式 + 顶栏/面板 HTML + 交互 JS），未触碰 v0.2 视觉语言基线（深浅主题、玻璃克制仅面板 / toast、trace 悬停浮现、reduced-motion / reduced-transparency、44px 触控、focus-visible 3px 环）。

### 2.1 按钮颜色统一：设置 / 回到顶部 / 主题共用一套（需求①⑥共用样式）
| 项 | 值 | 依据 |
|---|---|---|
| 共用规则 | `.fab, .back-to-top, .theme-fab` 同一条：`background:transparent`、`border:0`、`border-radius:0`、`min-width/min-height:44px`、12.5px/600、`color:var(--muted)`、`text-shadow:var(--ts-1)` | 需求①「设置颜色与回到顶部一致」；需求⑥「主题按钮字体颜色与设置/回到顶部一致」——三按钮同一套，天然一致 |
| 隐形 / 高亮 | 共用 `.trace`：默认 `opacity:.5`；hover/focus `opacity:1 + scale(1.04) + color:var(--accent)` | 与既有无框文字语言一致；44px 命中区无视觉框 |

### 2.2 网页端（1440）：回到视口角，去掉「锚到内容列」（需求②）
| 项 | 值 | 依据 |
|---|---|---|
| `.fab-anchor` | `position: fixed; right:16px; bottom:0;` 去除 `max-width/margin-inline` 镜像 | 需求②明确去掉「锚到内容列」；1440 内容列 880px 居中（右缘≈1160），视口右缘=1440，两按钮+主题落在右侧留白，不与内容重叠 |
| 不随内容列移动 | 滚动 1600px 后 `.fab-anchor` 仍 `right` 距视口右缘 16px、底缘贴视口 | 证据 `anchorStaysViewportCornerAfterScroll` |
| 面板 | 打开于按钮行上方（`bottom: calc(100% + 8px)`），不遮挡按钮 | 既有交互保留 |

### 2.3 iPad（1024）/ 手机（390）：底部「点击无效区」Dock（需求③）
| 项 | 值 | 依据 |
|---|---|---|
| 触发条件 | `body[data-width="1024"/"390"]`（width 参数模拟）+ `@media (max-width:1100px)`（真实视口平板/窄屏） | 需求③明确 1024/390；真实视口走媒体查询同规则，冒烟已验证 |
| Dock 本体 | `.fab-anchor` 展开为**整条底部**：`left:0; right:0; min-height:84px` | 与内容列同宽（1024 全宽、390 全宽），覆盖底部边缘避免按钮/内容重叠 |
| 拦截点击 | Dock `pointer-events: auto`；`elementFromPoint` 命中 Dock 本体 → 非按钮区域点击不穿透下层内容 | 需求③「该区域点击不穿透到下层内容」；底部内容（证据行 / 前往原文 / 页脚）被 Dock 挡住不会误触发 |
| 渐变模糊背板 | `background: linear-gradient(180deg, transparent 0%, var(--dock-bg) 58%)` + `backdrop-filter: blur(6px) saturate(130%)`；`--dock-bg` 深 `oklch(0.145 0.008 252/0.92)`、浅 `oklch(0.97 0.005 250/0.9)` | 需求③「底部渐变 + 轻微模糊/背板」；浅色 0.9 透明背景色在浅底上几乎融合、内容渐隐，深色 0.92 压暗淡出 |
| 按钮入 Dock | `.fab-row` 右下对齐（`align-self:flex-end; margin:0 16px 12px 0`），三按钮仍无外框纯文字 | 需求③「功能按钮放在这块 Dock 内」；44px 命中区保留 |
| 面板 | 打开后浮于 Dock 上方（`right:16px; bottom:calc(100%+8px)`），`panelBottom ≤ dockTop` 已断言 | Dock 不遮挡面板 |
| 降级 | reduced-transparency → 玻璃回退不透明 surface；reduced-motion 取消放大；触屏 `pointer:coarse` 提升基准对比 | 沿用既有降级链，Dock 背板仅弱化层级 |

### 2.4 设置面板点击外部收起（需求④）
| 项 | 值 | 依据 |
|---|---|---|
| 收起触发器 | `document` click 监听：面板展开且点击不在 `#draft-panel`、不在 `#fab` 时收起 | 需求④「点击面板外部自动收起」 |
| 保留 | 设置按钮 `click` 仍切换开合（`setOpen(panel.hidden)`） | 需求④「点设置按钮本身切换开合保留」 |
| 边界 | 点面板内部不收起；点 Dock 空白 / 页面任意处收起 | 已验证 `clickInsidePanelKeepsOpen` / `clickOutsideClosesPanel` |

### 2.5 设置面板正式内容：正式设置占位 + 调试控件 DRAFT 折叠（需求⑤）
| 项 | 值 | 依据 |
|---|---|---|
| 正式内容 | 面板头「设置 / 正式设置项待产品确认」；正式区 `语言 · 来源偏好 · 通知 · 显示密度` 各带「占位」角标 + 说明「正式设置项待产品确认」 | 需求⑤「正式呈现的内容不应当是宽度/状态切换器」；占位骨架待产品确认 |
| 调试控件 | 宽度 / 状态 / 降级模拟收进 `<details class="dp-debug">`，summary「调试控件 DRAFT」，默认折叠 | 需求⑤「调试控件移走或明显标注 DRAFT」；仍可供证据导出 / 回归用 |
| 主题调试 seg | 从面板移除（主题改单按钮驱动） | 避免重复入口 |

### 2.6 主题单按钮：显示当前主题、点击切换、置设置右侧（需求⑥）
| 项 | 值 | 依据 |
|---|---|---|
| 位置 | FAB 行内，`#theme-btn` 位于设置按钮右侧（顺序：回到顶部 → 设置 → 主题） | 需求⑥「移到设置按钮右侧」 |

### 4.1 关键断言（162/162 全过，按需求分组）
- **① 颜色一致**：三按钮 `color / textShadow / background / border / radius / opacity` 全同；`textShadow` 非 none。
- **② 视口角固定**：`.fab-anchor` `position:fixed`、`right` 距视口右缘 16px；锚宽度 ≈194px ≪ 内容列右缘 1160px；滚动后 `right` 仍 16px、底缘贴视口。
- **③ Dock**：1024/390 Dock 整条宽（left:0 / right=vw）、`pointer-events:auto`、`background-image` 含 linear-gradient、`backdrop-filter` 含 blur；三按钮 `getBoundingClientRect` 均在 Dock 内；`elementFromPoint`（Dock 中部、非按钮）命中 Dock 本体 → 点击不穿透。
- **④ 点击外部收起**：点面板内不收起；点面板外收起；设置按钮 `click` 先开后关（切换开合）。
- **⑤ 正式设置占位**：面板头含「正式设置项待产品确认」；正式区含语言 / 来源偏好 / 通知 / 显示密度 / 占位；调试 summary「调试控件 DRAFT」且 `details` 无 `open`（默认折叠）；面板仍为 `.glass` 且浮于按钮 / Dock 上方。
- **⑥ 主题单按钮**：`#theme-toggle` 不存在；`#theme-btn` 位于 `#fab` 右侧；深色初始「☾ 深色」/ 浅色初始「☀ 浅色」；点击后 `data-theme` 翻转且标签 / aria-pressed 同步。
- **保持**：10 主图 / 16 缩略图 / 10 前往原文；无页面级水平滚动；无页面 JS 报错。

### 4.2 冒烟补充（非 width 参数模拟）
- 真实视口 1024（无 width 参数）→ `@media(max-width:1100px)` 启用 Dock（`pointer-events:auto`、blur、0 报错）。
- 真实视口 1440 → 角落锚定（rightOff=16、无 Dock blur、0 报错）。
- reduced-motion：hover 回到顶部 `transform:none`（无放大）但 `opacity:1`（对比度浮现保留）；回到顶部瞬时滚动 `scrollY=0`。
