### 2.4 判定优先级（点击 / 滚动 / 缩放 互不干扰）

按以下顺序判定，任何一步命中即结束、不再往下：

1. **lightbox 打开时**：所有手势发生在 lightbox 层（z-index 200 全屏覆盖），时间线主图手势被天然隔离，互不触发。
2. **缩略图命中区**（`pointerdown` 落在 `.ph-thumb` / `.ph-thumbs` 叠层）→ 不启动主图滑切，保留“点击缩略图固定”与“悬停预览”。
3. **轻点（未位移/未超 6px）** → 不锁定为拖拽、不捕获指针 → 随后的 `click` 目标保持为主图 → 正常打开 lightbox（点击放大）。
4. **横向位移超过阈值** → 判定为滑切：`pointerup` 后记 `swiped` 标记，抑制随后的 `click`（不误开 lightbox、不误关），主图自然切图。
5. **竖向主导**（pointer `|dy|>|dx|` 或 wheel `|deltaY|≥|deltaX|`）→ 交还页面滚动（`touch-action: pan-y` + wheel 放行），不做滑切。
6. **lightbox 内**：`pointerdown` 落在 `.lb-nav`（‹› 按钮）→ 不启动滑动捕获，保证按钮 click 命中；落在画面上 → 拖动滑切；未位移轻点 → 点击背景关闭；`ctrl+wheel`（捏合/组合键）→ 不拦截，交还浏览器。

> 取舍说明：滑动与“点击放大”共用主图这一触发区。采用“位移超阈值才算滑切、未位移算点击”的经典判据，并在 `pointerup` 后置 `swiped` 标记抑制 click，保证两者不打架；这是不改变已确认布局下的最小判定改动。

## 3. 设计草案修订明细（index.html）

### 3.1 CSS
- `.tl-media.multi`：`touch-action: pan-y`（纵向滚动交还页面，横向手势由 JS 接管）。
- `.tl-media.multi .ph-main`：`cursor: grab`（拖拽中 `.swiping` → `grabbing`），提示可滑切；单图主图保持 `zoom-in`。
- `.ph-main` 增加 `will-change: transform, opacity`（滑切动画性能）。
- 布局/视觉 token 一律不动（6838E5 单主图 + 右下角缩略图保持）。

### 3.2 JS
- 新增共享工具：`prefersReducedMotion()` / `cancelAnim()` / `swipeThresh(el)`（阈值公式）。
- 新增 `switchMainBy(media, dir, animate)`：主图自然切图（滑出→换图→滑入），复用 `setMainImage` 联动缩略图 `is-active`。
- 新增 `bindMainSwipe(media)`（时间线主图）：
  - `pointerdown`（排除缩略图命中区；**不立即捕获**，轻点保持 click 命中主图）→ `pointermove`（超 6px 才锁定并 `setPointerCapture`，`translateX` 跟随）→ `pointerup`（超阈值切图并记 `swiped` 抑制 click；低于阈值回弹）。
  - `wheel`（横向主导、非 ctrl）累计 `|deltaX|` 超阈值切图，350ms 冷却。
- `bindMedia()`：拖拽滑切中跳过缩略图悬停预览（`.swiping`）；对每个 `.tl-media.multi` 调用 `bindMainSwipe`。
- `bindLightbox()`：
  - 新增 `wheel` 处理器（横向主导、48px 阈值、350ms 冷却，`slideSwap` 自然切图）。
  - `document` click 处理器：消费时间线主图的 `swiped` 标记（滑动后点击不误开 lightbox）。
  - **修复**：`startDrag` 在 `pointerdown` 落在 `.lb-nav` 时直接返回（不捕获），使 ‹› 按钮 click 正常命中（既有缺陷，按“按钮共存”修正）。

## 7. 错题自检

- 已检查错题集（`docs/collaboration/错题集.md`），**无命中**。
- 过程中发现并修正两类问题（均为实现细节，非设计方向变更）：
  1. **pointer 捕获重定向 click 目标**：主图 `pointerdown` 若立即 `setPointerCapture`，随后的 `click` 会以捕获元素为 target，导致 `e.target.closest('.ph-main')` 失效、lightbox 打不开。正确做法：**轻点不捕获、进入横向拖拽（超 6px）时才捕获**。同类问题在 lightbox `‹›` 按钮上暴露（点按钮变“点背景关闭”），一并修复为 `.lb-nav` 按下不捕获。
  2. **测试断言作用域**：`page.waitForFunction` 内模板字符串引用了 Node 侧常量（`R1M`），在浏览器上下文未定义而报 ReferenceError；改为以参数传入 selector。
- 修订仅作用于 `design/ui/F1+1-v0.2-全站设计/index.html` 与 `scratch/swipe-evidence-v0.2e.cjs`；未改动 `app/`、`docs/spec.md`、accepted ADR、`data/`；未触发部署/发布。
- 与已确认方向的取舍：本任务**只叠加**滑动切图，未推翻 6838E5 单主图 + 右下角缩略图布局；`wheel` 仅在横向主导时接管，纵向滚动一律放行，避免影响时间线页面滚动与详情页正文浏览。
