## 3. 什么是优质的发布视频(可操作标准)

以下标准提炼自三个 GitHub 来源的交叉验证:`30x-video` 的 16 条品味法则与 5 幕叙事规则(A,仓库内 rules/)、`video-shotcraft` 的判例式审美法则(A,references/aesthetic-rules.md,来自多支已交付宣传片返工复盘)、`vibe-motion/skills` 品牌发布视频 skill 的发布阻断清单(A,SKILL.md "Release blockers")。

### 3.1 结构:5 幕叙事(30x-video rules/narrative.md)

该仓库称此结构被 Stripe、Linear、Vercel、Arc 等产品的发布片采用(C 级,为仓库自述,未逐片核验),骨架固定、内容因产品而异:

| 幕 | 时间(40s 片) | 内容 | 要点 |
|---|---|---|---|
| Act 1 Logo | 0–4s | 品牌 logo 动画(真实 SVG) | 必须是观众看到的第一个画面;logo 只在首尾两幕出现;背景用品牌色渐变/微光,不用纯白纯黑 |
| Act 2 Hook | 4–12s | 全屏产品 UI + 一个交互动效 | 用真实页面;标题文字不得压在 UI 上 |
| Act 3 Showcase | 12–28s | 标题屏与 UI 演示屏交替,2–4 个功能小品 | 每个小品是不同页面;承载核心卖点 |
| Act 4 Proof | 28–34s(可选) | 数据可视化/社会证明 | 无证明数据则跳过、扩充 Act 3;企业级产品证明幕比花哨转场更重要 |
| Act 5 Close | 34–40s | Logo 锁定 + 标语 + CTA + URL | 逐字入场;结尾帧至少停留 1 秒 |

### 3.2 节奏判例(video-shotcraft aesthetic-rules R 组)

- **R1 关键信息落定后必须呼吸**:承载信息的元素落定后静止 ≥1s 再切镜;停顿优先给品牌记忆点(开头/结尾 wordmark 各 hold 满 1 秒),不随手给普通卡片。
- **R2 速度感来自加速度,不是匀速快**:飞入/滚动一律非线性缓动 + 错峰;批量元素入场用"越来越快"的硬加速并绑物理隐喻(如发牌),满板后静止 0.5s 再切下一拍;匀速直线运动读作廉价 PPT。
- **R3 宁慢勿快**:开场主体动作弧 ≥3s;模拟真实交互(打字、筛选、点击)按真人操作速度;初版几乎总是偏快,默认放慢一档。

### 3.3 质感判例(Q 组,与 F1+1 直接相关)

- **Q1 复刻既有页面必须用真实截图**:无头浏览器截整页 2x 纹理 + 元素级抠图 + 坐标 json;禁止手搓仿真 UI 冒充既有页面(有"手搓一下午整体作废"的返工判例)。手搓 UI 仅限抽象开场/品牌段等非复刻场景,且须过出版级质感门槛。
- **Q2 3D 透视下 UI 纹理按原生尺寸 2–4x 栅格化再向下采样**;文字发糊先查纹理分辨率链路,不要先动相机/景深。
- **Q3 镜头要稳**:亮场 UI 宣传片默认不加手持抖动。

### 3.4 反 AI 模板味黑名单(30x-video taste.md,逐条带用户裁决出处)

出现即暴露"AI 生成"的禁用模式(摘要对 F1+1 最相关的):

- 紫/蓝紫渐变背景;三段式"图标圆圈+标题+两行描述"特性网格;一切居中;统一圆角;装饰性色块/波浪分隔线;emoji 当设计元素;"Unlock the power of..."式通用标语;大数字+渐变色指标模板;卡片叠卡片。
- **扩散圆环/涟漪动效**、**心跳式缩放映脉冲**(用户原话裁决禁用;卡点只用于切镜时机,不做持续视觉脉冲)、**装饰性横线/分隔杠**、**符号装饰行**(星号/火花串)。
- 全屏动效资产上不再压文字——要么全屏无字,要么面板收纳、文字在外。
- 自检试金石:"把这视频给别人看并说'这是 AI 做的',对方会立刻相信吗?会,就重做。" 以及"高级 ≠ 复杂":加东西前先问减什么。

### 3.5 通用设计与认知原则(30x-video taste.md)

- 一帧一个论点;焦点元素须在大小/对比/位置/重量中至少赢两项;减法优先("盖住任一元素,画面变好就删掉它")。
- 峰终定律:观众最记得 Act 3 峰值与 Act 5 结尾,打磨预算向这两处倾斜;首因效应:最强的功能/数据放最前。
- 留白即高级感:成片约 40% 留白;标题帧 80%+ 留白。
- 单帧节奏预算:入场 15–20 帧、停留 80–120 帧吸收内容、退出 10–15 帧;观众读不完字就转场 = 该镜太短,"宁可砍一个功能,不要赶着讲四个"。
- 12 条场景自检清单(眯眼测试/3 秒测试/品牌替换测试/模板陷阱测试等)可直接作为设计部逐镜头验收表。

### 3.6 真实资产纪律(vibe-motion brand-launch-video-star "Release blockers")

1. 只用真实资产:logo、产品界面、吉祥物、包装**禁止重画/描摹/生成近似品**;logo 必须下载官方现行文件,禁止用 CSS/SVG 拼字标。
2. 展示真产品:演示真实功能、交互与输出,不用抽象特效掩盖薄弱的产品故事。
3. 动效确定性:每个状态由 frame/time 显式推导,不依赖渲染顺序或未播种随机数。
4. 宣称可核验:名称、功能、指标、口号、CTA 发布前对照官方来源确认。

### 3.7 声音( video-shotcraft sound-design / 30x-video beat-sync)

- BGM 先做节奏分析,切镜与幕边界卡在 downbeat;SFX 钉帧到具体动作(点击、翻页、落版)。
- 无声环境下的可读性(字幕/文案自足)属行业通识,本轮 GitHub 证据未直接覆盖,标为**合理推断**。

### 3.8 时长与规格(综合)

- GitHub 各方法论收敛区间:**15–40 秒、16:9、1920×1080、30fps** 为发布视频主片基准(video-shotcraft 模板 36.2s;30x-video 40s;brand-launch-video-star 默认 15–30s)。
- 竖屏 9:16 裁剪版(社媒分发)、海报帧/缩略图为常见衍生品(**合理推断**+各仓库 deliverable 惯例)。
