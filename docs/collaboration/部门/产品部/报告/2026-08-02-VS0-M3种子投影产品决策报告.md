# VS-0 M3 种子投影产品决策报告

产品部已正式 claim `TASK-20260802-D70CFC`，并对 VS-0 M3→Source 投影作出单一 `accepted / PASS` 实现决策。唯一 canonical 入口为 [ADR-M4-VS0-SEED-001]([M5-HOME]/Documents/F1+1/docs/decisions/system/2026-08-02-F1+1-VS0-M3种子投影-accepted.md)。

## 2. accepted 规则

### 2.1 六项 Source 缺失字段

| 字段 | accepted 规则 |
|---|---|
| `platform_allowed` | 固定 `unknown`；不满足 activation gate。 |
| `source_config_epoch` | 固定整数 `1`；只表示首个 local fixture epoch，不表示真实 provider 切换。 |
| `created_at` | `normalized_added_at + T00:00:00Z`。 |
| `updated_at` | 与 `created_at` 逐字相等。 |
| `created_by_ref` | `synthetic:seed-m3-v0`。 |
| `updated_by_ref` | `synthetic:seed-m3-v0`。 |

`source_safety_epoch` 不属于 derived 字段；它已存在于 M3 33 列，59 行按原值直读，旧 `local_only` 注记不覆盖 direct ownership。

### 2.2 `added_at`、时区与保守失败

严格接受 `YYYY-MM-DD 00:00:00`，并投影为同一日历日期：

```text
2026-07-31 00:00:00 -> Source.added_at = 2026-07-31
```

`created_at` 使用 `2026-07-31T00:00:00Z`，`updated_at` 相同。投影不推断时区、不跨日换算、不静默截断、不写 RFC3339 到 `Source.added_at`，不增加第二个 raw timestamp 字段；非精确午夜形状直接 fail closed。

### 2.3 Projection、provenance 与 hash

- 这是 local fixture projection，不是真值；59 行保持 `enabled=false`，`unknown`、`pending`、`proposed`、`null` 等保守值不升级。
- 原 M3 batch、fields、manifest、原始字节与 hash 保留；projection 记录输入 artifact hash、`M3-20260801-X59-01`、mapping/version、39 fields、59 rows、`external_calls=0`、`writes_to_base=false`、`non_authoritative=true` 和 `second_domain_schema=false`。
- 59 行按 `source_id` Unicode code point 升序排列；字段按冻结 `Source.required` 顺序。projection hash 固定为 `SHA-256(canonical-json-v1({fields, rows}))`，不做大小写折叠、locale 排序、trim 或隐式类型转换。
- 数据部 bridge 当前 candidate hash 为 `96d5caf625f62d059cc51a41d7c3b6a1db623d07cea00c4d256e2d841c693aa2`。后续只读 validator 需按本决策复跑并确认字节一致，VS-0 才能把 candidate 作为本地 seed 输入。
