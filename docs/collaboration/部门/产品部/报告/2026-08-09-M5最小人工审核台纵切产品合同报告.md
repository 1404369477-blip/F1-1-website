# M5 最小人工审核台纵切产品合同报告

## 1. 结果

已形成单一 `/admin/reviews` proposed 实现合同：

`docs/spec/F1+1-M5最小人工审核台纵切产品合同-v0.1.md`

合同闭合了 synthetic 待审核列表、证据核对、中文摘要编辑、批准/拒绝、批准后独立手动发布、唯一 PublishedProjection 和公开页刷新出口。合同不包含 `/admin/sources`、真实采集、外部 AI/媒体、自动发布、生产认证、跨网络 admin、Base/provider 或部署。

## 2. 单一真值与最小实体

- 只使用现有 Content、Summary、ReleaseBundle、ReviewDecision、Publication、PublishedProjection。
- 页面未保存输入不成为实体；持久草稿使用 `Summary(summary_status=draft)`。
- 编辑创建新 Summary version 和新 immutable Bundle，不修改旧 Bundle。
- 批准与发布分为两次明确用户动作；批准只创建 Decision 与唯一 queued Publication。
- PublishedProjection 只从同一 published Publication 派生；客户端状态、缓存和 toast 不成为真值。

## 3. 合同覆盖

- 页面层级、宽/窄屏行为与 18 类页面状态。
- 四个 mutation 的 closed 请求/成功响应 DTO：revision、approve、reject、manual publish。
- `GET /api/admin/operations/{operationId}` 内部只读收据，闭合断网、503、revision 新 bundle 未知与 publish reconcile 恢复。
- local-dev session、Origin、CSRF、expected hash/version、五 fence、manual-only、CAS 与幂等。
- stale/conflict/reconcile_wait/503 的查询优先恢复，禁止盲重试。
- 成功后公开详情与信息流仍走既有 projection-first GET。
- 状态、无障碍、安全负例、范围边界与回退验收。

## 4. 已验证

- `docs/spec.md`、accepted M4 Kickoff ADR、accepted v0.4 公开读模型 ADR、现有数据 schema/state machine 已只读核对。
- 现有状态可承载 draft、ready、approved、rejected、superseded、publish_queued、queued、published、reconcile_wait 与 blocked；Content 使用现有 state machine，Summary/Bundle 只使用冻结 enum 并等待数据字段映射，没有发现必须新增领域实体的冲突。
- accepted admin route、loopback local-dev、session/Origin/CSRF、manual_only、hash/fence、唯一 Publication/publicId 与 PublishedProjection 边界已逐项回指。
- 本任务未修改 app、data、Spec 或 accepted ADR，没有外部 I/O。

2. `/admin/reviews` 最终视觉预览尚未形成，用户尚未确认；正式实现不得开工。
