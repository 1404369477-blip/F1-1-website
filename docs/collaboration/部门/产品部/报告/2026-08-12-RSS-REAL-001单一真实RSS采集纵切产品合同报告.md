# RSS-REAL-001 单一真实 RSS 采集纵切产品合同报告

## 结果

已新增 `ADR-M5-RSS-REAL-001` accepted successor，并同步 `docs/spec.md` 与初版全功能追踪矩阵。用户授权只覆盖固定 M1 每 15 分钟读取 `https://www.motorsport.com/rss/f1/news/`，完整 RSS 响应不超过 1 MiB/60 item、选最新 20 条，写入隔离私有 SQLite 的 `pending_review` 候选。

旧 VS-RSS-0 三次请求和独立依赖确认口径已被 successor 取代，旧 draft 正文保持不变。`RSS-SAFE-001`、历史 ID `RSS-PILOT-002` 与 `REAL-SOURCE-003` 已从 `user-gated` 转为 `P1-blocker`；这三个状态表示授权已满足、实现与独立证据尚缺。

## 合同出口

- 三个逻辑表固定为 `source`、`ingest_run`、`pending_review_candidate`。
- 精确 URL、HTTPS/443、公共 DNS/IP、0 redirect、拒绝压缩、DOCTYPE/ENTITY/XInclude、条件请求、完整解析 60→20 与单事务写入均已冻结。
- 同 identity 内容更新只改机器层并递增 `source_revision`；采集器永不改人工字段或 `review_status`，通过人工基线落后于 source revision 派生“需要复审”。
- 失败必须形成唯一 reason code、聚合收据与下一动作；部分候选、validator 或游标不得提交。
- M1 部署采用精确 release/profile/manifest，先过 fixture、测试、安全，再做一次受控真实运行和 15 分钟调度；回退先停采集并递增 fence，再切上一 release，公开 synthetic 不受影响。

## 已验证

- 用户授权证据、TASK 范围、successor 状态与跨文档时态已逐项映射。
- 合同明确 RSS-only、私有待审、人工字段保护、公开 synthetic 和自动发布为 0。
- 未修改 app、data、design 或任何旧 accepted ADR 正文；旧 draft 也未改写。

## 未验证

- 固定 URL 当前是否直返 200、MIME、字段、`ETag`/`Last-Modified`、地区可达性和长期稳定性均为运行期 Unknown。
- XML 依赖与代码、私有 SQLite/migration、M1 LaunchAgent、15 分钟样本、失败恢复和回退均未实现或运行。
- 测试部与安全部尚未对同一候选给出 `P0=0/P1=0`；因此不得把 accepted 合同写成真实采集已上线。

## 错题自检

- 没有把用户对个人非商业 Beta 的决定扩大为自动发布、全文/文章页抓取、媒体使用、其他来源或公网 Admin 授权。
- 没有把 2026-08-08 的 50 条观察写成当前响应事实；运行字段保持 Unknown 并设置失败关闭出口。
- 没有让采集器覆盖人工字段或重置人工审核状态。
- 没有运行真实 RSS、安装依赖、修改 lockfile、执行部署或做冗余测试。
