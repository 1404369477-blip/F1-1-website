## 2. accepted 决定

### 2.1 U1｜物理隔离的双 profile/SQLite

- `m3-shadow` 使用 `.local/f1plus1.sqlite`，只承载 59×39 M3 影子 Source projection。
- `public-synthetic` 使用 `.local/f1plus1-public-synthetic.sqlite`，只承载 12 条 synthetic 公开阅读闭环。
- 每进程显式选择一个 profile；禁止 attach、合并、跨库反写或在同一 Source 表混入 59 行与 `src-active`。
- 两库使用 profile ledger 绑定 contract version、manifest hash、count 和 `synthetic_only/external_calls/writes_to_base` 安全标志，不匹配即拒绝启动。

### 2.2 U2｜最小 `mvp-local-v0.4` successor

- 保留 v0.3 的领域对象、状态机、幂等键、不变量、canonical JSON、TaskEnvelope 与 internal-only 边界。
- 只追加 editorial category、中文 lead/body/key points、来源 display/byline、访问/时间/媒体展示 snapshot 和对应 hash 输入。
- 12 个演示公开身份固定迁移为 `public-demo-*`。
- 每条必须经过 CapturedItem→Content→Summary→Bundle→approved ReviewDecision→Publication→PublishedProjection；不增加 `public_story` 或第二发布身份。

### 2.3 public API v0.1

accepted 端点只有：

```text
GET /api/public/feed?cursorAt=&cursorId=&source=&contentType=
GET /api/public/stories/{publicId}
```

合同冻结了：

- Feed/detail 的所有公开字段、类型、nullable、枚举和权威来源；
- `Publication.published_at DESC, PublishedProjection.public_id DESC` 排序；
- page size=12、LIMIT 13 判定 hasMore、筛选绑定 base64url cursor；
- 合法未公开 ID 的统一 404、非法 query/cursor/publicId 的 400；
- partial join/hash/fence 损坏的整请求 500；
- SQLite BUSY/LOCKED 的 503 + `Retry-After: 1`；
- closed Problem JSON、DTO `additionalProperties=false` 和 internal/private allowlist；
- projection-first 校验、相关内容 0–3 条和前端单一运行数据源。

## 3. 迁移与回退

### 迁移

1. 先记录 v0.3 artifact SHA、M3 59×39/e7a8、当前 DB schema receipt 与 12 条 UI 输入 hash。
2. 数据部在新 successor 目录生成 v0.4 machine contract/fixture/manifest，不修改 v0.3。
3. 通过只追加 migration 新建 public-synthetic DB，seed 事务原子写入 ledger、`src-active` 和 12 套图。
4. seed 后重读并复算 profile、manifest、实体、FK、hash 和 count；任一不符拒绝启动。
5. 数据、安全、测试门禁 P0/P1=0 后才允许 Repository/API/UI 接线。

### 回退

- migration/seed 失败：停止 Web，保留脱敏失败证据，回退整套应用版本与匹配数据库；不用 down migration。
- API 完整性失败：返回 closed Problem，不降级到静态 `DEMO_STORIES`。
- UI 接线回归：回退整个应用版本与匹配数据库，不并存两套运行读真值。
- M3 收据受损：拒绝启动并从准确备份/已验证版本恢复；public-synthetic 永不反写 M3。

## 6. 失败路径

1. profile 或物理隔离无法机械证明：停止数据/API 接线，`src-active` 不得进入 M3 59 行库。
2. v0.4 字段、FK 或 hash 无法唯一复算：数据任务失败，开发不得从 UI 猜测字段或生成伪 published 图。
3. read chain、hash、fence、profile 或 manifest 损坏：整个 feed/detail 请求返回 closed Problem，不跳行、不返 206、不使用静态 fallback。
