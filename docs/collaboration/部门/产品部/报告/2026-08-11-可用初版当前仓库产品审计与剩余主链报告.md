# F1+1 可用初版当前仓库产品审计与剩余主链报告

## 1. 审计结论

当前仓库已具备公开阅读、公开 API、本地 synthetic 处理链、SOURCE-MGMT-001 后端和多组封闭数据候选，但尚不能宣称“可用初版完成”。

唯一结论：**当前产品状态为 NOT READY。**

阻断来自三条真实用户主链尚未同时闭合：

1. 公开端当前代码与既有浏览器证据的候选哈希不一致，当前候选没有同根独立浏览器、测试、安全和设计收据；多媒体 V2 前端 DEV-MM-04 仍受用户视觉确认门约束。
2. SOURCE-MGMT-001 目前只有 raw 后端/API，没有真实 Admin 页面；最终安全复验仍等待数据任务 TASK-20260811-3D190C 提供精确机器 oracle，视觉 v2 manifest 也尚未获得用户精确确认。
3. 人工审核台没有 review-synthetic 运行 profile、页面或后端纵切；ADMIN-DECISION 与 ADMIN-VISUAL 两个独立用户门均未关闭。

现行全功能追踪矩阵共有 50 个 Function ID：17 complete、20 user-gated、13 P1-blocker。此计数只说明合同覆盖范围，不等于当前产品可交付。

本报告仅作当前仓库只读产品审计。没有修改 Spec、ADR、代码、数据库或设计资产；没有运行测试、build、浏览器或联网操作。

## 3. 五个问题的当前答案

### 3.1 公开用户可看什么

当前代码包含：

- 公开首页信息流；
- 独立故事详情页；
- feed/detail 公开只读 API；
- 搜索、分类筛选、主题、设置、响应式、内联展开、回到顶部、多媒体展示和灯箱相关分支。

当前可证明边界：

- 基础公开 API、12 条 public-synthetic 数据图及若干 UI 能力有历史 ACK 证据。
- 24 条 public-multimedia-synthetic 候选数据库文件存在，历史数据/后端任务有 ACK。
- 当前环境文件仍选择 public-synthetic，而非 24 条多媒体 profile。
- 当前 11 个公开源文件聚合哈希为 548e678b7c024b80f0345d3370210c3609375955915909d9f63075262c4df792；历史冻结候选为 7b1e8977c3e7296f4e5cf165b106bc322c2ef19dbd5e506f51e2c4ec92465281。
- 当前 BUILD_ID 文件哈希为 abca90f315b1a55e392bbc046d9440a6171e10ed72db1fc67816c98373561b0f；历史冻结候选为 8155e435b052ae87467671cfc0bdfc59bf931922eb55fcf16f03fc68a5efb1c5。

因此，公开端的“代码存在”已验证；“用户现在按正式启动路径可稳定完成完整公开旅程”证据不足。旧浏览器报告不能证明当前候选，DEV-MM-04 仍受视觉用户门约束。

### 3.2 管理员可做什么

当前已存在的 SOURCE-MGMT-001 raw 后端提供：

- 本地 session 与 CSRF；
- Source 列表、详情、新增、验证、激活、停止、退役；
- operation 查询与两类 retry/requeue；
- 仅作用于 source-management-synthetic 独立 profile。

当前缺口：

- App Router 中没有真实的 /admin/sources 页面；
- source-management 启动分支当前只启动 raw server，不启动 Next 页面；
- 已 ACK 的产品裁决只确认后继候选 B：同一 Node 进程、同一 raw listener、raw-before-Next、同进程 Next handler；实施仍受后端最终安全闭合与视觉 v2 用户确认约束；
- /admin/reviews、review-synthetic profile 和人工审核纵切均不存在；
- mock 采集、清洗去重、低质过滤和 mock 中文摘要已有本地 operator receipt 级 ACK，但尚不能经真实 Admin 审核台操作。

因此，管理员当前只有可审计的本地后端能力与 operator 级 synthetic 处理能力；真实 Admin 页面、审核与发布界面均不可用。

### 3.3 数据保存在哪里

当前仓库内可见四个本地 SQLite 候选：

| profile | 当前用途 | 当前证据 |
|---|---|---|
| m3-shadow | 59 条禁用 Source 基线与影子数据 | closed receipt 与 DB 文件哈希匹配；非业务真值 |
| public-synthetic | 12 条公开 synthetic 投影图 | closed receipt 与 DB 文件哈希匹配；当前环境默认选择 |
| public-multimedia-synthetic | 24 条多媒体 synthetic 候选 | 当前 DB 哈希与历史冻结候选一致；本次未找到当前 closed receipt，运行可用性证据不足 |
| source-management-synthetic | 59 条冻结基线引用加 1 条本地 source 变更 | closed receipt 与 DB 文件哈希匹配；独立单 writer |

当前没有 review-synthetic 数据库。各运行进程仍遵守单 profile、单 SQLite、禁止 ATTACH 和跨 profile 查询。仓库中的 backup/pre-update SQLite 副本位于同一故障域，不能当作生产备份或灾难恢复证据。

飞书 Base 仍是影子候选，不是业务真值；本任务没有读取或写入任何 Base。真实内容、真实媒体、provider 数据、生产数据库、生产备份均未启用。

### 3.4 怎样启动

现行文档给出的本地生产式路径为：

1. 使用固定 Node 24 运行时；
2. 校验环境与锁文件；
3. 对所选单一 profile 执行迁移与 synthetic seed；
4. build 后用 start 启动 loopback 服务；
5. 需要 mock 处理时，另按合同运行 worker 的 once 路径。

当前重要限制：

- 当前环境默认指向 public-synthetic 12 条图；要使用 24 条多媒体候选，必须显式选择正确 profile、数据库和 fixture，并绑定同一候选收据。
- SOURCE-MGMT-001 当前走 raw source server，只提供后端/API，没有 Admin 页面。
- review-synthetic 没有可启动实现。
- 开发模式存在已知运行时选项冲突，不作为完成定义的正式启动入口。

本次遵守任务禁令，没有执行上述命令。可启动性只确认到“存在文档、脚本和候选文件”；当前候选实际启动、端口、页面和恢复均未验证。

## 4. 唯一 MVP 完成定义

**MVP 仅在以下五项同时满足时完成；任何一项缺失均保持 NOT READY：**

1. **公开用户闭环**：同一当前候选哈希上，首页进入、筛选/搜索、继续加载、详情页、内联展开、错误与重试、主题/设置、响应式、无障碍和 0/1/4 图行为均通过独立浏览器、测试、安全与设计验收；DEV-MM-04 先取得精确视觉 manifest 用户确认。
2. **管理员闭环**：/admin/sources 采用已裁决的 B 拓扑形成真实页面并完成新增、验证、激活、停止、退役、两类 retry 和恢复；/admin/reviews 仅在 ADMIN-DECISION 与 ADMIN-VISUAL 均确认后形成审核与显式手动发布闭环。
3. **数据与处理闭环**：每进程单 profile/单 SQLite，59 条 Source 基线引用、synthetic 采集、清洗去重、低质过滤、mock 中文摘要、审核、公开投影的对象数、哈希、状态机、幂等、失败回滚和 closed receipt 在同一候选上可机械复算；不得新增第二业务真值。
4. **启动与恢复闭环**：一条固定 Node 24 的生产式本地启动路径可从干净状态重建候选，明确 profile 选择、迁移、seed、build/start、健康检查、停止、清理和 last-known-good 恢复；六格证据绑定同一 source/data/build/runtime candidate。
5. **边界闭环**：MVP 保持 local-only、synthetic-only、manual-only、loopback-only、external_calls=0。真实外部、Base 真值、自动发布、设备配置和部署继续关闭，直到各自获得独立精确授权。
