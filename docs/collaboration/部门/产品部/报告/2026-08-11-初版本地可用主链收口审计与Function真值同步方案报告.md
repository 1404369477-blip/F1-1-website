# 初版本地可用主链收口审计与 Function 真值同步方案

## 1. 唯一结论

当前仓库仍为 NOT READY。

本地初版的最短主链已经明确，且无需新增产品方向：

1. 数据部 B42C2E 固定唯一 SQLite/synthetic release candidate；

## 6. 唯一本地最短主链

依赖顺序：

- 已确认的公开视觉基线 5a84 + B42C2E 数据候选 ACK
- → 0F65C1 固定 source/data/build/runtime candidate 并完成实现
- → 当前候选独立测试
- → 同一 candidate root 独立安全
- → 同一 candidate root 独立设计
- → 产品按逐 Function 收据更新 12 个状态

B42C2E 与 0F65C1 当前可并行；0F65C1 在数据 release candidate 未 ACK 前不能自行复制记录或静态补第二页。开发完成后，测试、安全、设计可以并行复验同一不可变候选。

公开主链的完成出口：

1. 当前 12 个 P1 每项均有真实路由和操作入口；
2. 正常、失败、恢复证据逐项绑定同一 candidate root；
3. public-multimedia-synthetic 数据图、Repository/API、App 与 build 身份一致；
4. production loopback 启动、外部调用 0、清理 0；
5. 测试、安全、设计均 ACK，且没有 NOT_RUN、占位或历史 hash 拼接。
