## 5. 为开发部 6CD2FB 提供的落地契约要点

1. **范围边界**：只做前端呈现；不新增后端实体、不新增 DTO 字段、不创建第二公开真值；只从 projection-first feed/detail API DTO 读取。
2. **token 权威**：以 `F1+1-v0.2-token-map.json` + 本合同 §2 CSS 别名实现；不手写颜色/断点；浅色 `--faint`（4.64:1）临界勿再降。
3. **组件槽位**：时间线单列 max 920px、时间左列 64px（时刻 mono 11px 上对齐分类/日期 display 20px 下对齐标题）、主图限高 255px 不裁切、缩略图 40px（移动 32px）、单图不渲染缩略图、就地展开手风琴一次一个、证据行 `信源 · [作者] · 时间` + 前往原文（无作者不渲染作者段）。
4. **交互契约**：URL 参数生产只暴露 `theme/open/search`；`width/state/reveal` 为 draft 调试/QA 专用；lightbox 打开/关闭/焦点陷阱/返回触发点/Esc/方向键；缩略图悬停预览/移走恢复/点击固定/键盘固定；展开点击外部收起 + `scroll-margin-top:20px`。
5. **响应式**：1440/1024 同单列，390 时间/日期并排、轴节点隐藏、缩略图 32px、触控 ≥44px；`@container` + `@media` 兜底，无页面级水平滚动。
6. **可访问降级**：对比度引用 `F1+1-v0.2-对比度验证.md`（文本 AA 全过、`--border-strong` ≥3:1）；3px 焦点环 + 2px offset；44px 触控；reduced-motion（动画 .01ms、lightbox/展开跳过、滚动 auto）；reduced-transparency（玻璃→不透明 `--surface`）。
7. **M4 安全门禁保持**：无服务端 http fetch、图片 display-only（M4 media 仅 synthetic/none）、原文为普通 `<a href>` 导航、`REAL_*` fail-closed、`external_calls=0`。
8. **验收出口**：`npm run check` 全绿；状态矩阵（loading/empty/error/404/nomore/partial/offline）可查看；1440/1024/390 布局通过；键盘/焦点/lightbox 焦点陷阱通过。

## 7. 回指设计部（CA04A8）——草案待确认项

以下为草案内部不一致或交互细节缺口，产品部按硬约束**未自行改草案、未扩大范围**，仅固化为合同并回指设计部确认：

1. **展开详情是否含图集**：`design-system.md` §7 写"展开：中文提炼 → 详情图集（全部真实图）→ 底部证据行"；但视觉证据 `index.html` 将全部图片放在顶部媒体区（主图+缩略图），展开区仅中文提炼。本合同以 `index.html`（已确认方向的实际交互）为准；请设计确认"详情图集"是否为已废弃表述。
2. **缩略图是否截断**：`design-system.md` §8 提"缩略图完整图 + 截断模糊 `+N`"，但当前 `index.html` 实现为"无多图行/截断逻辑；缩略图全量呈现"。本合同以全量呈现为准；请设计确认 `+N` 截断是否保留。
3. **lightbox 关闭方式**：草案 lightbox 无**显式关闭按钮**，仅背景点击 + Esc；`index.html` 未实现完整焦点陷阱（仅 focus 进 + 关闭返回触发点）。合同已规定必需行为（焦点陷阱 + 返回触发点 + Esc + 建议关闭按钮）；是否需要可见关闭按钮请设计确认。
4. **`--blur` 值不一致**：`brand-spec.md` 为 18px，`token-map.json`/`design-system.md`/`index.html` 为 16px（低性能 8px）。本合同以 16px 为权威；请设计确认统一。
5. **验收宽度档位**：`design-system.md` §5 仅列 1440/1024/390 三档（v0.1 有 320/768/1200/1600）。本合同按 v0.2 三档；是否补 320/768 等档请设计确认。
6. **`open` 深链语义**：`token-map.json` 的 `open: r1…r10` 为草案 demo id；生产应映射为 feed 项 `public_id`。合同已在 §4.1 明确；如需限定开放范围请设计确认。
