# TASK-20260809-9AE33E｜Admin 私有访问与异机备份用户决策包报告

## 1. 结论

任务通过。已基于 ACK 的研究报告和现行专用 MacBook 合同形成一份 [proposed 用户决策包](../../../../decisions/system/2026-08-09-F1+1-M5-Admin私有访问与异机备份用户决策包-proposed.md)。当前供应商选择仍为无；A/B/C 只是互斥的下一阶段合同路线，A 为产品部唯一推荐的验证顺序。

本任务未修改任何 accepted ADR、Spec、app、data 或 design，也未安装、注册、付费、运行网络探针、生成或上传密钥、上传数据、创建资源或部署。

## 2. 三路线与推荐

| 路线 | 角色 | 当前结论 |
| --- | --- | --- |
| `ROUTE-A` 托管 Tailscale + restic/B2 候选 | 日常 Admin 候选的第一验证顺序 | **唯一推荐**；自管实体最少，先回答中国大陆双端网络适配；供应商和生产选型均未批准 |
| `ROUTE-B` Headscale + 自托管 DERP + restic/B2 候选 | A 失败或控制/退出自主性要求更高时的后继 | 运维面显著增加，大陆可用性仍 Unknown；不得由 A 自动切换 |
| `ROUTE-C` WireGuard 中继 + restic/SFTP 候选 | 默认关闭的冷备通道 | 不满足当前日常 Admin freshness；若补自建控制面即回到 B 重新决策 |

三路线均列明用户影响、公开事实成本、项目成本 Unknown、运维、风险、淘汰与退出。用户选择只授权对应的下一阶段本地合同编制。

## 3. 三条独立门与 Gate 顺序

- `N-NETWORK-ADAPTATION`：只证明目标 Mac/iPhone 网络到私有 origin 的适配；不证明 freshness、备份或 production。
- `F-FRESHNESS-5M`：closed 7 字段、可信 UTC、`issuedAt≤now<expiresAt`、`0<duration≤5m`、签名/policy/device/session；未来签发、回拨、解析/签名/事实 unknown、deny 或到期均关闭全部远程 Admin。
- `B-BACKUP-RECOVERY`：只证明一致快照、异机加密回读、`RPO≤15m`、`RTO≤4h` 和完整恢复。

执行顺序固定：

1. `GATE-A`：本地离线 synthetic 备份合同；仍须后继任务授权才实施。
2. `GATE-B-N`：另行批准后的双端网络适配窗口；业务 DB/内容/secret/备份载荷零上传，协议必需元数据逐字段 allowlist。
3. `GATE-B-F`：独立 freshness 窗口；不能由网络连通或撤权 UI 替代。
4. `GATE-C`：另行批准后的异机备份和恢复窗口；RPO 使用当前/事故时点相对最新已验证恢复点的数据年龄，RTO 终点包含 Admin、public-host、active projection、public GET 和临时能力归零。
5. `GATE-D`：失败后回用户决定递进或退出；不自动切换、不并行写主。

## 4. 不变合同

- `publicly_reachable_admin_listener_count=0`；端口转发、UPnP、隐藏 URL 和公网 Admin 隧道均禁止。
- `writer_count=1`；禁止第二写主、数据库双活和 public-host 反向提升。
- Mac/iPhone 等价；overlay 不替代应用 passkey/session/Origin/CSRF/CAS/fence。
- 专用 MacBook 不承担日常个人工作。
- public-host 独立、公开只读、可丢弃。
- `RPO≤15m`、`RTO≤4h`、加密异机异故障域恢复点、manifest/hash 与隔离恢复演练。
- production manifest 和所有真实实施继续未授权。
