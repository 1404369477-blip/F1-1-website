# TASK-20260809-F27F25｜旧 WPA 临时本机运行与安全网络升级 v0.4 报告

## 1. 结论

任务的文档出口已闭合：旧 WPA/低安全性网络被记录为脱敏风险事实；推进顺序固定为先 `TEMP-LOCAL`、后 `SECURE-NET`。当前只形成 planning-only 合同、closed-set manifest 与固定 Mac 交接提示词，没有运行本地服务，也没有读取或修改真实设备、网络、账号、数据和密钥。

`TEMP-LOCAL` 仍需后继精确授权，且最多允许本机 loopback、synthetic fixture、`externalCalls=0`。旧 WPA 不进入安全网络、FileVault 启动前 SSH、远程恢复、RTO/RPO 或生产放行证据。

## 3. 已确认、官方证据、建议与 Unknown

### 3.1 已确认

- 固定设备脱敏事实仍为 MacBook Air（M1，2020）/ 8GB / macOS 26.5.1、可长期接电、Wi-Fi only。
- 当前 Wi-Fi 被 macOS 标记为旧 WPA/低安全性。
- 用户希望先做本机临时运行，后升级到安全网络。

以上内容不包含 Wi-Fi/路由器地址、SSID、密码、MAC、IP、序列号或其他唯一标识，也没有保存或散列截图中的标识。

### 3.2 官方证据

- Apple 路由器安全建议优先 WPA3 Personal 或 WPA2/WPA3 Transitional；在更强模式不可用时采用 WPA2 Personal（AES）；WPA/WPA2 mixed、WPA Personal、WEP 和 TKIP 属弱设置，应避免。来源：[Apple：Recommended settings for Wi-Fi routers and access points](https://support.apple.com/en-us/102766)。
- Apple 的 FileVault 部署文档对 Apple silicon + macOS 26 或更高版本描述了有条件的 SSH 启动解锁；Wi-Fi 路径只列此前连接过的开放网络或 WPA2-PSK。来源：[Apple：Intro to FileVault](https://support.apple.com/en-ca/guide/deployment/dep82064ec40/web)。

### 3.3 产品建议

- `TEMP-LOCAL` 只保留固定 Mac 本机 loopback + synthetic 的最小可逆路径。
- `SECURE-NET` 的最低目标为 WPA2 Personal（AES）或 WPA2/WPA3 Transitional；独立网络/网关是未来可选方案，不是 TEMP-LOCAL 文档前置。
- 只有此前连接、DHCP 保留、网关私有 VPN、蜂窝外网重启/FileVault 演练和恢复全链分别过门后，才重新评估远程与生产。

### 3.4 尚未验证

- 当前旧 WPA 的精确协议/cipher、路由器型号/固件、DHCP、CGNAT、升级能力和回退能力。
- 固定 Mac 的 FileVault、Remote Login、Firewall、Sharing、UU、睡眠、资源和应用运行状态。
- 新安全网络候选、此前连接、DHCP 保留、私有 VPN、蜂窝外网、FileVault 启动阶段、现场/冷备、旧主 epoch fence。
- 本地候选 hash、Node/lock/profile、loopback 监听、synthetic 运行、关闭与回退收据。
- `RPO≤15m`、`RTO≤4h` 和任何生产能力。

## 4. 合同边界

### TEMP-LOCAL

- 当前状态：`planning_only_not_authorized`。
- 未来后继授权上限：`loopback_only`、`synthetic_only`、`externalCalls=0`、单 profile/单 writer、manual-only。
- 继续关闭：非 loopback、LAN/overlay/公网、真实 provider/媒体/账号/数据/Base/AI/发布/部署、安装/登录、UU/SSH/FileVault/网络变更。

### SECURE-NET

- 当前状态：`future_gate_not_authorized`。
- 最低安全目标：WPA2 Personal（AES）或 WPA2/WPA3 Transitional。
- WPA3-only/802.1X 不推定满足 FileVault 启动前条件；UU 或普通 Tailscale 宿主应用不构成启动前网络证据。
- 网络升级、路由器/网关、账号、密钥、SSH/FileVault、实机重启和部署仍需新的精确授权。

## 5. 已验证

1. v0.3 SHA-256 复算等于任务固定值，字节未覆盖。
2. v0.4 successor、提示词和 manifest 均已落盘；manifest 可被 JSON 解析。
3. manifest 的三个闭集文件 bytes/SHA-256 与当前源文件逐一相等；readOrder 与闭集一致。
4. manifest 的所有实施、登录、网络、SSH、FileVault、UU、外部 I/O、真实账号/数据、备份上传、部署和生产授权均为 false。
5. v0.4 和提示词只保留一个下一步问题；问题只询问是否允许后继任务进入精确 TEMP-LOCAL 前门禁。
6. 目标文件的脱敏扫描未发现 IPv4、MAC、UUID 或已赋值的 SSID/账号/设备唯一标识；标准 loopback 仅作为能力类别表述。
7. 当前任务没有安装、登录、创建账号、启动监听、访问外部 provider、读取系统网络配置、修改设备/网络、上传或部署。

## 6. 错题自检

- 没有把旧 WPA 写成可接受的安全网络、启动前远程恢复证据或生产前置。
- 没有把 planning-only 文档写成已运行、已部署或已验收设备。
- 没有把 TEMP-LOCAL PASS 外推为 LAN、远程、FileVault、RPO/RTO 或生产 PASS。
- 没有记录、散列或编码截图中的地址与唯一标识。
- 没有覆盖 v0.3，也没有修改 app、data、design、accepted ADR 或真实资源。
- 没有把独立网络/网关写成已选择、已购买或已配置。
