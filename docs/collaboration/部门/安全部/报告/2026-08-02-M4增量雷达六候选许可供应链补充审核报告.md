总体判定为 **FAIL（真实/生产/商业准入失败）**。这项判定不阻断 A 层本地研究：

- **A / Green**：只允许将能力概念重写为本地 fixture、离线 parser、确定性状态机或 UX mock；输入为 synthetic，external_calls=0，禁止 secret、DNS、HTTP、socket、subprocess、浏览器和自动发布。

- **C / Red**：未来商业化、对外展示、收费或生产真实采集均关闭。代码页面声明 MIT 不提供新闻、用户内容、媒体、平台 API、摘要/翻译或商业再展示权。

## 5. A 层 synthetic 允许边界

六个候选均允许吸收少量可验证的结构概念，但 A 层仅是本地研究，不是候选安装或真实能力：

1. NewsPrism/AI News Open：固定 synthetic source payload，验证 canonicalization、dedup、事件聚类、人工 override、冻结 snapshot、replay 和 hash；不出站、不调用模型、不写 Feishu/Telegram/WeChat。
2. OmniWire-MCP：固定本地 RSS/Atom/JSON/HTML fixture 和本地配置，验证 DTO、超时、429/5xx、熔断、dead-letter；不启动 npx/MCP，不读取远程 RSS_FEEDS，不做 HTML 网络请求。

## 6. P0/P1/P2、生产硬阻断与停止条件

### 6.1 P0 直接能力阻断

- 外部 LLM、向量库、搜索或第三方 API key 与原文/用户数据同时存在。
- 自动发布或发布目标（Feishu、Telegram、WeChat、静态站、邮件）可由默认配置、CLI 参数、admin token 或环境变量开启。
- OmniWire 的 npx/远程 package、远程 RSS_FEEDS、任意 URL/HTML 网络请求或未审 lifecycle。
- News Digester 的 admin/admin 默认凭证、共享数据库/worker/邮件路径。
- 未经授权的 Product Hunt/上游内容抓取、重大复制、摘要/翻译或对外镜像。

P0 命中即停止候选的 B/C 路径，回到 A 层 fixture；不能通过把 provider 名称换成 mock、增加重试或隐藏 UI 开关来消除。

### 6.2 P1 与 P2

- P1：精确许可证条款、依赖/锁/SBOM/签名/漏洞/lifecycle、维护收据、来源 Terms/robots、内容/媒体/删除/缓存/保留、第三方模型 DPA/训练退出、地域/中国大陆可达性、商业合同任一 Unknown。
- P2：README 的“production-ready”、commit/follower/launch 热度、UX/架构相似性、研究适配度。P2 只能用于排序，不能提升准入等级。

### 6.3 立即停止条件

命中任一条件即停止当前候选并记录脱敏 reason：

- 许可证、依赖来源、平台/来源条款、数据留存/删除、商业权利或地区边界不能由一手证据确认。
- 出现远程配置、npx/安装脚本、未知 postinstall/lifecycle、任意重定向、SSRF、HTML/XML 解析外连、提示注入或 secret 暴露。
- 出现默认凭证、超出 allowlist 的 provider/scope、自动发布、共享数据库/邮件、浏览器登录态或代理绕过。
- 发生 403/429/付费墙/验证码/robots 禁止、异常 DNS/私网解析、不可解释的未知结果或预算/保留超限。

### 6.4 回滚

回滚动作固定为：禁用该候选 provider/capability；移除临时环境变量和测试凭证；恢复上一份 fixture、lock、manifest 与 hash；清理本地临时缓存但保留脱敏审计事件；确认 external_calls 回到 0；将所有未确认数据标记为 blocked/withdrawn。禁止用另一个未授权候选替换失败路径，禁止删除或覆盖历史报告。
