## 6. 开发部 6 项偏差安全评估

| # | 偏差 | 安全评估 | 级别 |
|---|---|---|---|
| 1 | 主图/lightbox 用**合成占位 data-URI SVG** | **安全。** `placeholderImage()` 的 SVG 字符串只拼接 `TONE_GRADIENTS` 中**硬编码**十六进制颜色（night/blue/amber/violet/slate 五组静态值），**DTO 受控的 `mediaDescription` 只进入 `alt` 属性、不进 SVG 数据**；经 `encodeURIComponent` 封包。即便未来把 DTO 数据放入 SVG，浏览器对 `<img>` 内 SVG 采用「静态上下文」——脚本/外链/交互被禁用，不构成 XSS。数据 URI 自包含、无外联，display-only 符合 R6/R7 的 synthetic 边界。 | 无 |
| 2 | 「前往原文」**禁用态**（DTO `originalLink` 恒 `enabled:false/url:null`） | **安全（M4 fail-closed）。** zod `.strict()` 强制 `url:null` → `hasOriginalUrl` 恒 false → 渲染「原文暂不可用」，`<a href={story.originalUrl ?? ""}>` 分支当前**不可达**，前端不伪造任何外链。**未来真实内容接入前**，`DEPLOYMENT-PREP.md §3.2` 已要求校验 URL scheme（拒 `javascript:` 等）；建议届时前端视图层再加运行时 scheme allowlist（不仅依赖服务端）。 | P2（未来加固，当前不可利用） |
| 3 | 作者段按「unknown/空」隐藏（DTO `byline` 恒非空串） | **安全。** 纯展示判定（`hasAuthor()` 归一化后排除 empty/unknown/未知），对 closed DTO 字段只读，无注入/无越界。 | 无 |
| 4 | 搜索置于顶栏（仅首页） | **安全。** 客户端过滤经 `timeline-search.ts` 模块级 store；输入写入 input `value`（React 转义）并经 `setHashParams` 的 `encodeURIComponent` 写回 hash；`parseHashParams` 的 `decodeURIComponent` 带 try/catch；`history.replaceState` 失败 noop（sandbox-safe）。无服务端交互、无注入。 | 无 |
| 5 | 原生 `<img>` 替代 `next/image`（3 条 lint 警告） | **安全。** 为支撑 data-URI 占位 + `tabindex=0/role=button` 键盘放大与 lightbox 语义，原生 `<img>` 是合理选择；`next/image` 不适合 data URI 且包装 DOM 会破坏焦点/角色。`loading="lazy"`、`src` 为 data URI（无网络）、`alt` React 转义；**未用 `eslint-disable` 隐藏警告**（如实保留）。无 XSS/SSRF。 | 无 |
| 6 | theme localStorage 键改为 `f1p1-theme` | **安全。** localStorage 为客户端偏好，`isF1Theme()` 仅接受 `dark/light`，非法/缺失回退默认；`read/write` 均 try/catch。旧键不再读取（无迁移）无安全影响。 | 无 |

**6 项偏差合计：P0=0、P1=0、P2=1（仅 #2 未来加固项）。**
