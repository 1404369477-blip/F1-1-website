# 首条 RSS 纵切权利与入口安全门禁

## 1. 唯一结论

**FAIL（P0=0、P1=2、P2=0）。** 当前不允许任何真实 RSS 请求、新来源启用、内容持久化、翻译/摘要、图片处理、Base/provider 切换或生产展示。本结论只基于已 ACK 的研究部和数据部本地产物，未访问外部来源。

### P1-1：Formula1.com 候选的拟持久化范围超出现有权利证据

数据包 `U-CAD1DB-001` 请用户确认保留 GUID、title、short description、author、canonical link 和 fetch metadata。研究部已记录 Formula1.com RSS 官方条款对商业聚合、存储、摘录、翻译和修改的限制。用户批准只解决项目侧意愿，不会产生第三方内容许可。

**关闭要求：** 真实请求前将 Formula1.com 降为“用户批准后的瞬时结构观测”，默认不持久化 feed title/description/author，不作翻译、摘要、历史归档或 second-hop；仅可输出请求成败/失败、字段存在性和计数等无内容诊断。若需保留任何 feed 内容，先由权利人书面许可或法务确认独立合法依据，并将证据范围、用途、地域、期限、归因和删除义务写入门禁。

### P1-2：真实 RSS 运输安全合同仍缺精确值

数据包已定义游标原子推进、幂等、有界退避、权利 unknown、无媒体和人工审核出口，但没有冻结 SSRF、HTTPS/重定向、DNS/IP、响应字节上限、MIME/XML、超时、日志脱敏与前端 CSP 的可实现合同。直接开放会让受控 feed 入口变成内网访问、资源耗尽或第三方跟踪出口。

**关闭要求：** 开发必须实现下节的最小合同，由安全/测试以恶意 URL、DNS 变更、重定向、超大/慢响应、错误 MIME、XML 实体/深度和日志泄漏负例复验通过后，才可回到用户批准门。

## 3. 开发必须实现的最小入口合同

1. **精确 allowlist：** 配置只接受固定 `https` origin + 精确 path；拒绝用户信息、fragment、非 443 端口、IP literal、通配子域和任意查询参数。候选 URL 只能由审核后配置选择，不接受请求传入 URL。
2. **DNS/IP 绑定：** 每次连接和每次重定向都重新解析；在实际 connect 目标上拒绝 loopback、private、link-local、multicast、unspecified、CGNAT、文档/保留地址与 IPv4-mapped IPv6；解析结果混有非公网地址时整体拒绝。
3. **重定向：** 默认 0 次。若某固定 feed 经独立证据必须重定向，最多 1 次，目标仍须命中另行冻结的精确 HTTPS allowlist，并重做 DNS/IP 检查；不转发 Authorization/Cookie。
4. **方法与超时：** 仅 GET；连接超时 3s、首字节 5s、总超时 10s。超时、中断和部分响应均不解析、不持久化、不推进游标。
5. **响应限制：** 声明长度或实际解压后流量超过 1 MiB 立即中止；默认不接受 content-encoding，如实现 gzip 则 1 MiB 上限必须作用于解压后字节。只允许 `application/rss+xml`、`application/xml`、`text/xml`，且每次仍做 XML 结构验证；拒绝 HTML/JSON/缺失 MIME 和 MIME sniffing。
6. **XML 解析：** 禁用 DTD、DOCTYPE、外部/参数实体、XInclude 和网络 schema；限节点数、深度、单字段长度与条目数（pilot 最多 20 items）；非完整 parse 一律 fail-closed。
7. **并发与退避：** 单来源最多 1 个在途请求，不做盲重试；沿用数据包 network/5xx `60/300/900s`、429 `Retry-After` 夹在 `60..3600s`、parse `300/900/1800s` 后 dead-letter。每次重试重读 authorization/stop/两 epoch/TaskEnvelope fences。
8. **原子性和删除语义：** 仅在所有新 observation 与 inbox intent 同一事务成功后推进 cursor；304 不产生 observation。RSS 条目消失只进 `missing_unconfirmed`，不自动删除或宣称撤稿；权利通知/明确 404 后按冻结规则删除。
9. **日志与观测：** 仅记录 source_id、事件时间、状态/原因码、字节/条目计数、耗时、重试次数和不可逆哈希。不记录完整 URL/query、feed 内容、标题/描述/作者、响应头原文、IP 清单、stack、cookie、token 或本地路径。错误对外仅固定 reason code。
10. **公开出口/CSP：** pilot 数据只进人工审核，不生成 Publication/PublishedProjection。媒体始终为空；公开页保持 `img-src 'self' data:` 等现有本地边界，不为 RSS/enclosure 新增第三方 host。原链须使用已校验 HTTPS URL、新窗口隔离与 `noreferrer`/`noopener`，禁止转发内部参数。

## 4. 停止条件

任一条命中立即终止请求或 pilot，不推进游标，不保留部分内容：

- 用户未对精确 source/frequency/retention/second-hop 作明确批准，或授权/平台/适配器/stop/fence 任一非通过。
- 条款、robots、权利通知或来源行为与已批准用途冲突，或查询日后证据过期无法确认。
- URL/redirect/DNS/connect IP 任一越出精确 allowlist 或命中非公网地址。
- TLS/证书错误、超时、超大响应、错误 MIME、DTD/实体、解析不完整、schema 异常、稳定身份缺失或新不可识别字段导致语义不确定。
- 出现第三方媒体下载/代理/缓存、正文 second-hop、未批准的 metadata second-hop、Base/provider 写入、自动发布、公开投影或日志泄漏。
