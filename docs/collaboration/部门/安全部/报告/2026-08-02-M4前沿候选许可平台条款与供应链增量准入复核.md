# M4 前沿候选许可、平台条款与供应链增量准入复核

## 1. 结论与判定范围

本报告承接安全部 TASK-20260802-4D3684、研究部 TASK-20260802-D11DCA、综合方案 TASK-20260802-D9DA43，并根据 TASK-20260802-780373 的候选清单做增量复核。AI Hot 版本按三个时态层记录：v1.2.1 的固定历史提交 `fcba3adcf5def1ccd4bb688de93060227471b129`；旧报告中只读观察到、没有完整 SHA 的 v1.2.2；本轮由统筹预检观察到、并由同源 sparse clone 复核的当前 main `f430c4b11eb7ce715d77768ff787855b7a025187` 与 SKILL metadata v1.2.3。v1.2.3 的静态文件事实已按固定 SHA 读取并校验；远端服务端、真实 API 行为与条款执行仍保持 Unknown，不能把静态包证据延伸为平台或商业准入。其余复核对象包括 X、Reddit、Instagram、RSS/Atom/WebSub、RSSHub、Miniflux、FreshRSS、changedetection.io、Crawl4AI/Firecrawl、n8n/Huginn、OpenF1/Jolpica，以及本地 skills/tools/agent 方案。

本报告的决策粒度如下：

- A 层：M4-local-fixture-v0，仅合成数据、fixture/mock provider、离线 parser、deterministic summary、fixture/none media、manual-only 本地投影。A 层结论为 Green/可放行，前提是 deny-all、无 secret、无 DNS/socket/HTTP/subprocess、无真实数据和无自动发布。
- B 层：未来个人非商业或单平台授权 spike。B 层不因“个人使用”自动获得平台访问、内容再展示或删除豁免；必须有具体平台、账号归属、最小 scope、书面许可或官方批准、速率/费用上限、TTL/删除处理和全链路收据。缺任一项即 blocked。
- C 层：未来商业化、对外展示、收费服务或生产真实采集。C 层当前整体 FAIL。商业硬门槛尚待用户确认，所有商业授权、平台合同、内容/媒体/翻译/摘要权利、区域/DPA、成本、删除/撤回和供应链证据未齐前不进入 C。

代码许可证不能替代平台内容权、用户内容再展示权、媒体权利、摘要/翻译权、地域合规或商业合同。本报告给出准入判定和证据缺口，不构成法务意见，也不替用户做商业选择。
