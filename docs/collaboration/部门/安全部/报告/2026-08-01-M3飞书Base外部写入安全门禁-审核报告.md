# M3 飞书 Base 外部写入安全门禁审核报告

## 审核对象与结论口径

- 审核对象：[产品部 M3 执行包](../../产品部/报告/2026-08-01-F1+1飞书Base影子建表-M3执行包.md)、[ADR-SOURCE-001](../../../../decisions/system/2026-08-01-F1+1-信源库A到D演进路线-accepted.md) 和 `data/x-source-inventory-v0.csv`。
- 本报告只复核外部写入方案及执行门禁，没有访问、创建、修改、分享或删除任何真实飞书资源。
- `PASS` 只表示执行包可在本文检查表和停止条件约束下进入 M3 单线执行。它不表示 Base 已创建、59 条已写入、真实 ACL/表单行为已通过或后续真值/provider/采集/发布门禁已放行。
- 统筹部在本轮提供的脱敏只读证据为：`lark-cli auth status --json --verify` 返回 `verified=true`、`identity=user`，且精确标题与关键词检索均未匹配到目标 Base。该证据用于确认当前起点；安全部没有重复执行 live auth 或 Base 查询。

## 审核标准

1. 任务级最小权限和最小动作；所有外部动作固定为用户身份，禁止切 bot。
2. 凭证、私密标识、私人联系方式、运行遥测等敏感信息不进入 Base、payload、日志或报告。
3. Base 与手机表单不公开分享，不生成或传播公开链接。
4. 资源必须先精确解析并使用真实返回 ID，禁止重复创建。
5. 部分成功、超时和未知响应必须先全量读回，禁止盲重放。
6. 记录以 `migration_batch_id + source_id` 幂等，以 `migration_batch_id` 完成 59/59 对账。
7. 本次只建影子资源并导入候选，禁止真值、provider、采集、同步、启用和发布切换。

## 独立证据

### 1. 本地输入与映射

- `data/x-source-inventory-v0.csv` 的 SHA-256 独立重算为 `bbb84a7f8f625e8106ae6e0b2714a363940dbf3f20dcbbf300fa6552de1ac01b`。
- CSV 为 1 行 header + 59 行数据；13 个输入字段无空单元格。
- 大小写不敏感的 `source_id` 唯一值为 59、重复组为 0；`canonical_url` 唯一值为 59、重复组为 0。
- 59 个 canonical URL 和 59 个 evidence URL 均使用 `https://x.com/`；canonical URL 无 query，evidence URL 均含来源 query。
- 独立解析执行包 JSON：写入字段 33 个且全部唯一，映射模板 33 个 cell，引用的 CSV 字段均存在；`enabled=false`，`migration_batch_id=M3-20260801-X59-01`，`change_reason` 明确写明不切真值/provider。
- 对 CSV 做凭证/密钥/邮箱模式扫描，没有命中 access token、refresh token、API key、secret、password、Bearer、cookie、session ID、private key 或邮箱。该结果只覆盖当前静态文件；M3 不允许真实手机表单提交，后续若要开放提交必须另过数据治理门禁。

### 2. CLI 本地权威说明

- 本机 `lark-cli 1.0.68` 可用；完整读取了其内嵌 `lark-base 1.2.2`、`lark-shared 1.0.0` 及本任务涉及的字段、批量创建、CellValue、视图筛选和表单题目 reference。
- CLI 规则要求默认显式使用 `--as user`；用户身份权限失败时先停止并处理用户授权，不能直接切换 bot 猜测重试。
- `+title-resolve` 是只读命令，返回多候选时必须消歧；Base、表、字段、视图、表单和记录后续命令必须使用真实返回 ID。
- `+record-batch-create` 单批上限为 200，59 条可串行单批；写前必须读取真实字段结构，系统字段不可作为普通 CellValue 写入。
- 视图更新要求先读现状；表单题目创建/更新是写操作，需先列出现有题目并使用真实题目 ID。

### 3. 鉴权与资源起点

- 本地脱敏收据记录 2026-08-01 的用户身份 verified、token valid，并列出 Base create/read/update 等 scopes；收据没有保存 token、用户名称、open ID、app ID、tenant ID 或资源 ID。
- 统筹部本轮只读复核进一步确认当前仍为 `identity=user`，目标 Base 的精确标题/关键词检索均无匹配。
- 已授予 scope 中包含本次不需要直接使用的 `base:app:update`、`base:field:update`、`base:record:update`、`base:table:update` 和 `base:table:delete`。令牌级最小范围尚未达到；本次只在固定命令白名单下放行：写命令限资源 create、必要的 `view-set-*`、必要的 `form-questions-update`，以及首次 59 条或经完整读回证明缺失子集的 `record-batch-create`；禁止 Base/table/field/record update、全部 delete、raw API 和 `--yes`。若执行环境不能实施该隔离，结论自动转为 `FAIL` 并停止写入。

## 必测失败路径与反向探针

1. **同名竞态：** 由统筹部维持单一执行者和互斥执行窗口，在创建前后各做一次精确标题解析；若另一执行者在间隙创建同名 Base，后一次应停止。保留已创建资源，不删除重建，冲突处置另行授权。
2. **模糊命中：** 关键词返回近似标题但完整标题不同；必须逐项比较完整标题，不能把“无精确同名”写成“无任何候选”。
3. **超时但已成功：** 模拟/遇到 batch 响应未知；先按批次键读回。若已有 1–58 条，只验证并补缺；禁止再次提交 59 条。
4. **部分成功含错行：** 现存子集任一字段与合同不符；预期行为是停止并保存 record ID 对照，不补缺、不覆盖、不删除。
5. **表单默认暴露：** 新表单自动带出内部字段或默认分享；预期行为是停止，不提交手机数据、不分发链接、不继续 59 条导入，转人工只读核验。
6. **权限失败：** 用户身份返回 scope/ACL 错误；预期行为是停止并处理用户授权，禁止改用 bot 或 raw API 绕过。
7. **未知枚举：** 最终 payload 含合同外 select 值；预期行为是在写前失败，防止平台自动新增选项。
8. **敏感输入：** 最终 59 行 payload 出现凭证、私人联系方式、内网地址或运行日志，或执行清单出现真实表单提交；预期行为是写前失败，不向 Base 提交、不复制到报告。
9. **分页漂移：** 回读出现重复 cursor/offset、页重叠、分页中断或计数在分页期间漂移；预期行为是停止写入并从第一页重新只读聚合，不能沿旧游标补写。

## 停止条件

出现任一项，M3 外部写入立即停止，当前 PASS 不再适用：

1. live auth 非 verified、token invalid、身份不是 user，或无法保证所有命令显式 `--as user`。
2. 无法实施固定命令白名单，或计划出现 bot、raw API、Base/table/field/record update、任何 delete、分享/权限扩张、`--yes`。
3. Base 解析多候选、候选不可读、完整标题不确定、同名合同冲突或创建竞态。
4. 输入 hash、59 行、header、33 列映射、枚举、唯一性或默认值任一漂移。
5. 发现凭证、私密标识、私人联系方式、内网 URL、运行遥测或错误日志将进入 Base/日志/报告。
6. Base 或表单为公开、任何人可访问、分享状态不可验证，或出现未确认成员/链接；Base ACL 未通过时不得创建子资源，表单分享未通过时不得导入 59 条。
7. 表单可见题目不是精确两项，内部状态暴露，执行清单出现 `form-submit`/真实手机提交，或产生 workflow/自动入主表行为。
8. 任一资源名称、类型、父 ID、字段、视图、表单合同读回不一致。
9. 响应超时/未知、分页未读完、cursor/offset 重复、页重叠、部分成功状态未完成逐行验证。
10. 本批大于 59、少于预期且现存子集有错、出现重复/越批，或 `migration_batch_id + source_id` 不能唯一对账。
11. 任一记录被启用，或身份/相关性/可监控性被未经验证地写成肯定结论。
12. 业务真值、provider、epoch、Collector、同步器、采集、发布或公开审核门禁发生变更。

## 残余风险

- **令牌能力偏宽：** 当前用户 token 含 update/delete scopes。固定命令白名单只能降低误用概率，不能从令牌层移除能力；若后续要把风险降到更低，需要由平台/用户授权流程收敛 scopes。
- **TOCTOU 竞态：** 统筹部已确认当前无匹配 Base，但标题搜索与创建之间没有原子唯一约束；单一执行者、互斥窗口和创建前后双查仍不能完全消除平台索引延迟与并发竞态。
- **真实 ACL 与默认分享行为未验证：** CLI 本地说明证明命令形状，不能证明租户中的资源级 ACL、表单默认分享或 UI 最终状态。
- **手机输入不可完全预判：** M3 禁止真实提交，因此本阶段不验证 `raw_url` 与自由文本 `capture_note` 的运行时内容控制；后续开放提交前仍需受控成员、输入约束、人工复核和数据治理门禁。
- **平台部分成功语义：** 批量写入和多资源创建可能非事务；批次键、真实 ID 和全量读回可以止损，不能提供跨资源原子回滚。
- **身份与业务判断未完成：** 当前 59 条只证明本地 URL 唯一和保守状态，未证明平台稳定账号 ID、账号身份、F1 相关性、可监控性或授权有效性。
