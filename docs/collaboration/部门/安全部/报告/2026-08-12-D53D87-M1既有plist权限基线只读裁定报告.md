# M1 既有 plist 权限基线只读裁定报告

## 1. 结论

**PASS；P0=0，P1=0，P2=1。**

`TASK-20260812-85E90D` 的首错 `IDENTITY_MODE_INVALID` 属于观察谓词把所有旧 plist 强制限定为 `0600` 所致。M1 当前 `com.f1plus1.quick-tunnel.plist` 实际为 `0644`；它由当前用户拥有、单硬链接、真实普通文件，父目录 `0700`，group/other 没有写权限，且结构化敏感扫描未发现 token、secret、password、private key、credential、cookie、session、auth key 或非公开敏感环境变量。

因此，**旧 live 只读观察基线可接受该精确 `0644`**，无需先停服或 chmod。新生成、stage、final 或 prepare 替换的 plist 继续强制 `0600`；本裁定不允许新工件降级到 `0644`。

本轮仅通过既有 SSH alias 执行只读 `stat/realpath/shasum/plutil/launchctl print` 和本地结构化 plist 解析。修改、chmod、launchctl变更、服务操作、页面访问、数据库访问、传输和代码修改均为 0；唯一业务写入是本报告。

## 3. 权限裁定

### 旧 live 观察门允许的唯一 mode 集合

旧、已加载且只读观察的这三份 LaunchAgent plist，可接受：

```text
mode ∈ {0600, 0644}
```

其中 `0644` 只有同时满足以下机械谓词时才可接受：

1. 精确白名单路径与 label；
2. 当前 UID owner；
3. regular、非 symlink、`nlink=1`、realpath 精确；
4. 父目录当前 UID、真实目录、mode `0700`；
5. `(mode & 0o022) == 0`，即 group/other 不可写；
6. `plutil -lint` 成功；
7. 结构化 plist 中无 secret/token/password/private-key/auth-key/credential/cookie/session，EnvironmentVariables 只允许本任务冻结的非敏感 key集合；
8. SHA 与本报告基线一致，loaded label/state/PID没有超出任务允许的自然状态。

任一 group/other writable、异主、symlink、multi-link、越界 realpath、敏感内容 world-readable 或未知 mode 都必须按 P1 首错停止。

### 新工件硬门

所有后续新生成或新写入对象，包括 task stage、delta、final release、prepare plist、deployment manifest与回退副本，仍须使用原合同的 owner-only `0600`（目录 `0700`）。旧 live `0644` 只构成读取与比较的兼容基线，不能被复制为新工件 mode，也不能让 `atomicReplace` 恢复/生成路径接受新的 `0644`。
