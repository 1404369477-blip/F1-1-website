- 实际：真值切换、版本携带和回滚合同满足该期望；持久化围栏的实现细节尚未验证，继续列入未覆盖。
- 结果：静态合同通过。

## 自设计反向探针

1. **重复/缺失探针：** 在内存副本中分别复制一条和移除一条记录，机械检查会触发数量、唯一性或集合差异，原件不会被改写。
2. **handle 复用探针：** 只命中 canonical URL 且缺稳定平台账号 ID 时，产品合同要求 `needs_review`，不会自动合并旧 `source_id`。
3. **部分分页探针：** 全量读取中途缺页时，完整性与总量检查失败，临时文件不能原子替换 last-known-good。
4. **本地篡改探针：** 快照 checksum 或 manifest 链不匹配时，采集器拒绝新文件，恢复只能从 Base 全量重建。
5. **紧急停用探针：** deny overlay 只减不增，不能新增来源、修改身份或长期替代 Base；因此可以快速止损而不形成第二业务真值。
6. **旧任务竞态探针：** provider/配置版本变化后，旧 `expected source_config_version` 或旧 epoch 的任务只保留审计，不更新当前信源状态。
