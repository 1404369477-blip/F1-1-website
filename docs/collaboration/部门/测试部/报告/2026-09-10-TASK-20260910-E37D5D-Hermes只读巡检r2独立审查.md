## 已关闭发现

### P2：未来 RSS 时间被夹到零并表现为健康

r1 `database.ts` 的 `age()` 接受未来 30 秒内时间并返回零年龄。独立 fixture 仅将 `source.last_success_at` 改为采样时刻后 15 秒，即得到 DB/RSS `healthy` 与 `lastSuccessAgeMs=0`。这会隐藏同一主机上的时间异常。

r2 改为严格拒绝负年龄。原反例现在得到失败关闭的未知采样，不能再输出健康。旧证据保留在 `adversarial-sampler.json`；r2 反例结果写入独立新文件，未覆盖旧结果。

### P2：备份 manifest 的公开 pointer 成员未绑定登记字段

r1 仅核对 manifest 的数据库成员哈希和 generation 路径，未将 `projection/active.json` 成员哈希与 `backup_recovery_point.projection_pointer_sha256` 比对。独立 fixture 将登记 pointer 哈希换为另一合法格式哈希后，合法 view/JOIN 与两份真实签名仍通过，备份被报告为健康。

r2 增加该直接绑定，原反例得到 `BACKUP_MANIFEST_MISMATCH`。该反例不代表生产已有此损坏；它验证采样器能识别登记与签名 manifest 之间的可检测不一致。

### P2：安装配置 resources/prompts 层级与已安装 Hermes 不符

安装 helper 初版将 `resources:false`、`prompts:false` 放在 server 顶层，而 M1 `tools/mcp_tool.py` 的 `_select_utility_schemas` 从 `tools` 子对象读取。当前 wrapper 不广告这两类能力，初版尚未造成实际多工具暴露，但配置中的禁用声明无效。

最新版 helper 将其放入 `tools:{include:[get_site_status],resources:false,prompts:false}`，已检查对应源码及独立重跑的安装自测。sampling、elicitation、并行工具调用仍明确关闭。

## 权限、安装和运行边界

固定工具入口没有模型可控 SQL、URL、路径、shell 或维护动作。DB 使用只读连接、query_only 和固定 SQL；不加载业务 bootstrap/writer。HTTP 只有三个固定 GET 目标，公网同时绑定固定目标和隧道进程身份，拒绝重定向并限制时间、header/body 大小。HTTP、文件、数据库和进程原始内容不会进入模型 DTO；输出采用闭集字段、原因、有限数值及时间校验。

备份结论的范围为当前合法登记、manifest、固定公钥和两份签名回执的绑定及年龄。工具明确返回 `offHostCiphertextReread=false`、`restoreExecuted=false`，本次没有完整重读离机密文或重演恢复。原合法 JOIN 与既有 supervisor 一致，不能凭文件存在推导有效恢复点。

helper 是独立 operator，未进入 payload 或 MCP。它拒绝未知 CLI 覆盖、链接/硬链接、文件集合或 SHA 不符、同名目标、YAML 重复键/merge、非空或已有同名 MCP 配置；先独占创建 release 与原字节备份，再在同目录原子替换。原配置的 SHA 和身份在提交前重验，回退同时绑定安装后 SHA 与原始 SHA，出现并发更改会停止。

helper 的 advisory lock 只协调遵守此锁的 helper 调用；SHA/身份检查与 POSIX replace 之间不具有内核级条件替换保证。已审安装说明如实披露该边界，执行窗口须由主控保持单一配置操作者。该限制已纳入结论，未宣称隔离同 UID 任意写者。

既有 Hermes 与生产同用户且保留通用终端能力，本切片只约束新增工具，未构成整个通用助手的系统隔离。

## Gateway 与微信出口

已安装 Hermes 的 `/reload-mcp` 分支负责 MCP 重连、工具刷新、会话工具变更提示和命令回复，不走 Gateway 启动自动恢复或计划重启通知。微信使用文字确认，用户应在原会话发送 `/reload-mcp`，收到提示后在 300 秒内发送 `/approve`，等待新增 server/工具的结果，再发状态查询。`/always` 会持久修改审批偏好，此次不要求使用。

旧会话下一普通消息会根据新的 enabled_toolsets 缓存签名重建 Agent，继承新增 MCP。当前会话忙时命令会被拒绝并要求等待。安装 helper 不发送命令、不重启、不自动代用户发消息。

最终交付继续保留四层状态：本地独立审查、M1 固定工具有效采样、Gateway 热加载、用户微信真实收件。后两层未有证据时不得标为完成。
