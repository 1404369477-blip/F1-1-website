## P1

### P1-01：lightbox Escape 关闭后焦点未返回触发图

- 打开单图 lightbox 后 `role=dialog` 精确为 1，主内容 `inert=true`。
- Escape 经过关闭过渡后 dialog=0，但 `document.activeElement` 落到 `body`，没有返回原“放大图片”触发按钮。
- 违反任务要求的“lightbox 焦点/返回”，影响键盘用户连续操作，判 P1。

### P1-02：production 控制台重复出现 React minified error #418

- 同一次验收窗口捕获两条同源 production console error，错误码均为 React #418，来源为本地 Next chunk。
- 页面表面仍可交互，但任务明确要求 console 验收；重复 hydration 类错误说明运行态存在客户端/服务端内容不一致风险，判 P1。

### P1-03：设计中的真实多图出口没有正式可达数据路径

- accepted DTO 只有单个 `media`，当前 production 数据只能呈现 0 或 1 张图。
- 设计和实现保留缩略图、多图滑动/方向键翻页等用户能力，但正式 feed/detail API 无法提供使这些出口真实可达的数据。
- 按 COR-20260809T102214-960E65，“设计内任何无真实可达出口的功能（含多图）应列 P1/阻断”，故判 P1，不再以 `NOT_RUN` 视为完成。
