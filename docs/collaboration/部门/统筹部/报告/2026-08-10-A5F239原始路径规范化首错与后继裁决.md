# A5F239 原始路径规范化首错与后继裁决

## 结论

`TASK-20260810-A5F239` 在第一个独立安全向量即证明现行候选存在一项 P1：原始 target `/api/admin/alias/../session` 在 `assertRawAdminRequest` 内先经 WHATWG `URL` 规范化为 `/api/admin/session`，随后作为合法路径返回 `RawAdminContext`。raw authority 因此没有在框架或 URL 规范化之前拒绝 dot segment。

这项结果使 `TASK-20260810-91AF6E` 的后端候选失去晋升资格，但不否定它已经证明的类型、构建、loopback 生命周期、业务 HTTP 和 closed receipt事实。缺陷发生在正式实例和数据库打开前；没有外部调用、正式 DB 写入、监听器、profile lock、WAL/SHM 或临时根残留。

## 最小修复合同

开发后继只允许修改 raw target 前置校验与对应聚焦测试：

1. 在调用 `new URL(...)`、路由匹配、body 读取和 runtime 访问之前，从 request target 精确切出 raw path 与 query。
2. raw path 对 literal `.`/`..` segment、反斜杠和任何 percent-encoded path 字节失败关闭；query 继续交由现有列表查询 allowlist 处理，不能因路径修复删除合法筛选能力。
3. URL 解析后的 pathname 必须与通过前置校验的 raw path 字节等价；任何规范化差异均拒绝。
4. 聚焦向量至少覆盖 literal `./`、`../`、大小写 `%2e` 组合、encoded slash/backslash、literal backslash、absolute-form 与现有合法 session/list+query。
5. 不改 session/CSRF、业务路由、SQL、SQLite、no-egress/listener、依赖、UI、Spec 或 accepted ADR；不打开正式 DB，不启动产品实例，不重复 91AF6E 全链。

修复候选只运行一次固定 Node24 聚焦测试和一次 typecheck。通过后必须重新创建测试与安全 successor；A5F239 的其余攻击面保持 `NOT_RUN`，不能继承为 PASS。
