# 390px 移动筛选弹窗局部滚动 P1 整改报告

## 结论

范围内实现已完成。设计部实测的 `340×104` 异常来自移动筛选面板的 `position: fixed` 位于带 `backdrop-filter` 的工具栏内，玻璃效果建立了局部固定定位包含块。

移动断点下，工具栏现按既有设计规范降级为不透明 `surface.1` 并关闭 `backdrop-filter`；筛选面板使用 `calc(100vw - 16px)` × `calc(100dvh - 16px)` 的视口工作区、`border-box`、横向裁切和整面板纵向滚动。关闭、五个分类与确认控件继续保留至少 44px 高度，既有 dialog 语义、焦点进入、Tab 环绕、Escape 关闭、焦点归还、四类 contentType 映射、主题与 reduced-motion 逻辑未改。

## 改动

- `app/src/app/globals.css`：移除移动工具栏产生 fixed 包含块的玻璃效果，明确筛选面板视口尺寸与溢出边界。
- `app/src/tests/public-ui.test.ts`：新增一个聚焦布局合同测试，覆盖移动不透明降级、视口尺寸、横向溢出、整面板滚动和 44px 触控下限。
