## 6. 无重复实体与单写者方案

### 唯一 Source schema

`source-fixture.ts` 的 exact 39 字段 `SourceRow` 与 canonical parser 是唯一 Source 合同入口。新 DB 的 `source_config_fixture` 只保存 local overlay 行；baseline 59 行每次从 pinned 文件读取并校验。Repository 返回 `baseline ∪ local` 的有效集合并按 `source_id` 排序。任何 API DTO 只能派生，不得再声明一套 Source 字段表。

### 唯一 runtime handle 与 writer

`withSourceManagementRuntime(...)` 持有单进程 singleton `DatabaseSync` handle。HTTP command、同步 validation、activation worker、attempt/dead-letter 都进入同一串行 writer lane；worker 不启动独立数据库进程或第二 handle。每次 ready 检查 `database_list` 仅有 `main/temp`，ATTACH 保持禁止。

CLI migrate/seed/receipt 只在 runtime 未持有任务 DB owner/profile lock 时运行。按已 ACK 的 v0.2 与数据合同，`database.ts` 和 source-management runtime 必须实现进程内唯一 handle、串行 writer lane，并拒绝 CLI/runtime 并发、第二实例与第二 handle；锁的具体机械实现属于开发实现选择，不外推给 v0.3。若现有安全打开/锁原语无法满足该门槛，应作为独立实现 blocker 停止。

### 无新依赖

SQLite 使用 `node:sqlite`，identity 使用 `node:crypto`，HTTP/UI 使用现有 Next/React，解析使用现有 Zod。没有发现需要新增 npm 包的理由。

## 9. Public 零漂移与回退

### 零漂移

- source-management 使用独立 profile 和独立 canonical DB；public runtime profile allowlist 不增加 source-management。
- Admin runtime 不打开旧 public DB；旧 profile 完整性采用已 ACK closed receipt 和 secure file hash，在 runtime 外核对。
- public 零漂移 manifest 必须逐文件列出：根 `layout.tsx`、`globals.css`、`F1PageShell`、`app/src/server/public/**`、公开 API routes、公开 stories feature/pages、旧 profile DB/closed receipts、`app/package-lock.json`；禁止用目录通配符掩盖新增或漏项。每个实现批次结束逐文件比较。
- Admin 样式使用独立 CSS module。若冻结设计要求修改根 layout、公开壳层或全局样式，当前最小影响面即失效，必须先由产品/设计明确 route-group 拆分与 PUBLIC-16 新边界。
- source-management route 只在对应 profile 注册；public profile 下 Admin route 必须不可达，source-management profile 下 public 业务 route 必须按 successor 的精确边界拒绝。

### 回退

- 不提供 down migration，不改旧 profile。
- 未发布候选失败：停止 source-management route selection，关闭/checkpoint 新 profile，保留失败收据；只有同时满足任务归属、候选身份、预期路径/owner/mode/hash 的机械候选才可由独立授权清理。
- canonical 已建立但验收失败：保持 fail-closed，不修改/回填旧 M3/public DB，不用旧 DB 作为 fallback。
- UI 回退只撤销 source-management scoped 文件/样式；public 文件要求 hash 零漂移。
- 任何 rollback 都要复核旧 profile closed receipts、public 源码与 package-lock；若有漂移，升级为阻断并停止自动处理。
