## 2. 按合同落地明细

### 2.1 token 与主题

- 颜色按合同 §2.1 全部 OKLch 值落地于 `:root/[data-theme="dark"]` 与 `[data-theme="light"]`：`--bg/--bg-elev/--surface/--surface-2/--fg/--fg-strong/--muted/--faint/--border/--border-strong/--accent/--accent-deep/--signal/--on-accent/--focus/--ok/--danger`。
- 浅色 `--faint`（4.64:1，临界）未再降透明度/亮度；`--border-strong` 用修正后 ≥3:1 值。
- 字体：display `Barlow Condensed → 思源黑体 CN → PingFang SC`；body `Inter → 思源黑体 CN → PingFang SC`；mono `SF Mono → Menlo → Consolas`（`font-variant-numeric: tabular-nums`）。字号按合同：标题 20/700、日期 20/600、摘要 14.5/1.7、提炼 14/1.6、证据 11.5、分类 11、时刻 11 mono、状态码 44/800。
- 间距 `--s-1…--s7`、圆角 `--r-sm/md/lg`、图片 4px 硬边。
- 降级链：`prefers-reduced-transparency`/`[data-rt]` → 玻璃不透明；`prefers-reduced-motion`/`[data-rm]` → 动画 `.01ms`、直播圆点静止、`scale` 取消、搜索框保持展开；低性能 `blur(8px)`；`forced-colors` 取消玻璃/用系统色。

### 2.2 时间线条目

- 单列居中 `max-width: 920px`（`.app` + `.timeline`）。
- 时间左列 **64px**：时刻（mono 11px）上对齐分类行、日期（display 20px）下对齐标题行；发丝轴 `left:78px`、节点 `left:74px top:34px`（9px、`--border-strong` 1.5px 边、`--bg` 底）。
- 主图：原始比例 `max-width:100% + max-height:255px`、**不裁切**、4px 圆角、柔和投影、`cursor: zoom-in`。
- 缩略图：40px（移动 32px）、opacity `.55`/hover `1`/激活 `--accent` 边；**单图内容不渲染缩略图**（当前 DTO 恒为单张 synthetic 占位 → 生产无缩略图）。
- 就地展开手风琴：`0fr→1fr` 240ms、**一次一个**、`aria-expanded`/`aria-controls=det-{id}`、展开聚焦 `#tl.is-focusing`（其余条目 `opacity:.38 + grayscale(.85)`，触屏 `.5/.7`）、展开后 `scrollIntoView({block:'start'})` + `scroll-margin-top:20px`（reduced-motion 用 `auto`）、**点击核心区外部自动收起**并移除 URL `open`。
- 证据行 `信源 · [作者] · 时间`；作者为 `unknown`/空时跳过作者段（含分隔符）；来源/作者/时间直接显示有效信息，不带「来源」「作者」等标签。
- DOM 槽位对齐合同 §3.1：`li.tl-item[data-id] > .tl-time[aria-hidden] + .tl-entry > button.tl-summary-btn[aria-expanded][aria-controls] + .tl-media > img.ph-main[tabindex=0][role=button] + .tl-collapse > .tl-detail#det-{id} + .tl-ev`。

### 2.3 主图 / 缩略图 / lightbox

- 主图为可聚焦元素：`tabindex=0 role=button aria-label="放大图片"`，Enter/Space 打开 lightbox；`mouseover/mouseout` 事件委托到文档级（缩略图预览路径保留，当前单图不触发）。
- lightbox（`createPortal` 到 `document.body`，避免被 `body.lb-open .app` 灰度滤镜误伤）：
  - `role="dialog" aria-modal="true" aria-label="图片放大预览" tabindex=-1`；打开聚焦容器、关闭聚焦返回触发元素。
  - 可见关闭按钮 `.lb-close`（48px，任务要求）；Esc / 背景点击 / 关闭按钮均可关闭，淡出 180ms。
  - 多图时 ‹› 翻页按钮 + `lb-count`（`aria-live="polite"`，`N / M`）；方向键翻页（序号取模回绕）；**Tab/Shift+Tab 焦点陷阱**（可聚焦项：翻页/关闭）。
  - 打开从源图位置 `getBoundingClientRect` 缩放放大到居中（WAAPI 340ms）；背景 `.app` `grayscale(.85) blur(4px) opacity(.35)`；放大图 `max 70vw/70vh`。
  - `prefers-reduced-motion` 跳过缩放/淡入淡出。

### 2.5 交互与 URL 参数

- **生产只暴露 `theme/open/search`**：
  - `theme`：初始主题（URL 优先，其次 localStorage `f1p1-theme`，缺省 dark）；写 `html[data-theme]`/`body[data-theme]`；主题 seg 切换持久化。
  - `open`：按 feed 项 `public_id` 预展开并高亮（`#tl.is-focusing`），不自动滚动；无匹配忽略。
  - `search`：初始过滤词；渲染后对已加载条目应用过滤，输入实时同步 URL。
- **`width/state/reveal` 为 draft/QA 专用**：以 `IS_DEV = process.env.NODE_ENV !== "production"` 显式隔离；生产构建不注册。`state` 强制渲染指定状态（QA 证据/回归）；`width` 设 `body[data-width]` 模拟断点；`reveal=1` 设 `html[data-reveal=true]` 强制痕迹显形。
- hash 参数：`location.hash` 分隔 `&`/`=`、值 `decodeURIComponent`；写回 `history.replaceState`（沙箱失败 noop）；`state!=='timeline'` 时移除 `open`。
