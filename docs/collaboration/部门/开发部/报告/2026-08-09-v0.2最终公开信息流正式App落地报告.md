## 2. 对抗审查与 P1 收口

实现稳定后由独立只读 reviewer 复核，冻结设计 hash 再次匹配，P0=0。发现的可修 P1 均已收口：

1. 主图 pointer/wheel/click 的误点击锁统一使用 `event.timeStamp`，消除 epoch 与相对时钟混用。
2. lightbox 在容器初始焦点、首尾按钮和异常焦点位置均执行 Tab/Shift+Tab 环绕；打开时页面主区 `inert`，关闭时恢复并把焦点还给触发图。
3. 缩略图视觉尺寸保持桌面 40px、移动 22px，外层原生按钮提供 44×44px 命中区。
4. 初始请求失败且浏览器离线时优先显示 offline；加载更多失败只显示 partial 的单一恢复动作。
5. inline detail 区分 404 与通用 error；中止/失败会清理请求登记，error 提供显式重试。
6. 展开定位不再把 API `publicId` 插入 CSS selector，改为遍历 `.tl-item` 并精确比较 `dataset.id`。
7. ≤1100 Dock 补齐渐变、16px blur、饱和度、点击拦截与 reduced-transparency 关闭路径。

单媒体 DTO 与真实多图验收的冲突属于任务声明的 failure path，按 §0/§5 保留 NOT_RUN，不通过扩 DTO 或补造数据绕过。
