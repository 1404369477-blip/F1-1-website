## 1. 范围与实现结论

本任务仅实现公开信息流 `/` 与内容详情 `/stories/[publicId]`，使用 12 条明确标注为“本地合成演示资料”的静态资讯，覆盖赛事新闻、车手社交、名宿/历史、赛场趣事四类。

已落地的体验范围：

- 共享 `F1PageShell`、TopBar、移动菜单、深浅主题、键盘焦点和响应式容器；
- 首页 Featured、分类筛选、关键词本地筛选、默认/空/来源受限/no-more 四种可见状态；手机 320–767px 使用可关闭筛选面板，已选分类、关键词和状态会保留为可清除 Chip；
- 卡片的合成 CSS 媒体占位、无授权图片状态、来源元数据、明确禁用的原文入口；无图卡片与无图详情均继承基础媒体和详情媒体布局；
- `/stories/[publicId]` 详情的中文摘要、关键点、来源与原文状态、相关内容；
- 不存在的 `publicId` 由 `notFound()` 进入同段 `not-found.tsx`；
- 首页导航仅在 pathname 为 `/` 时标记 `aria-current="page"`；详情及详情 404 不会错误标记首页为当前页面；
- 纯函数 Vitest 覆盖演示数据数量与分类、本地筛选、状态输入、详情查找与相关内容。

没有新增依赖、没有改 `package.json`、`package-lock.json`、P1 安全文件、Spec、accepted ADR、data 或 design；没有启动真实 provider/Base/Collector/AI/媒体/发布/部署，也没有发出外部请求。
