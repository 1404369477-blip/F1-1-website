## 3. 物理边界

### 3.1 七表与状态

- Bundle 以 `(candidate_id,bundle_revision)` 和 `bundle_hash` 唯一，保存闭合 `public_payload_json` 与独立私有 `editor_notes`；INSERT guard 要求当前 candidate 的 `source_revision/source_payload_hash/editor_*` 与 public payload 精确一致。
- Decision 对 `bundle_id` 唯一且不可变；approved 必须绑定当前最新 Bundle hash，rejected 必须有 trim 后 1–500 字原因且不携带 approved hash。
- Publication 在批准时只能以 `queued` 插入，`public_id/bundle/decision/hash/generation` 不可变；状态更新只接受合同列出的有限迁移。
- PublishedProjection 只有对应 Publication 已进入私有 `published` 后才能插入，记录不可更新或删除。
- ProjectionOutbox 对 Publication 唯一，`delivery/idempotency/reconcile/snapshot generation/manifest hash` 与闭合 TaskEnvelope 逐字段绑定；状态机和 identity 更新均 fail closed。
- AdminOperation 保存固定 method/path/type、request/response hash 与最终 receipt，插入后不可变。
- AuditEvent 使用单调 `audit_seq`、唯一 event hash、previous hash 与闭合脱敏 payload；UPDATE/DELETE 均由 trigger 拒绝。

SQLite 不提供本任务允许范围内的 SHA-256 SQL 函数，因此 canonical hash 在 `mapping.ts` 写入前计算、读出后重算；SQL guard 继续负责关系、CAS、状态、唯一性和 JSON 身份绑定。后继 Repository 必须调用这些 validator，不能把 JSON 列当作任意 payload 袋。

### 3.2 公开 allowlist 与私有字段

`ReviewBundlePublicPayloadSchema` 只接受合同固定字段；`PublicProjectionRecordSchema` 只接受：

`publicId/publishGeneration/projectionHash/contentType/state/titleZh/summaryZh/publishedAt/sourcePublishedAt/sourceTimeStatus/source/media/originalLink/detail`。

真实外链限定为 HTTPS `www.motorsport.com`、空 userinfo、空端口或 443、无 fragment。公开媒体固定 `null`，状态固定 `media_missing`，详情首版固定 `leadZh=summaryZh`、`bodyZh=[summaryZh]`、`keyPointsZh=[]`。`editor_notes/editorNotes` 进入公开 payload、projection 或 TaskEnvelope 时会被 strict schema 拒绝。
