## 8. 备份 V2 当前阻断

候选位于 `scratch/TASK-20260829-BACKUP-V2-UPGRADE/working/`，尚未部署。独立对抗审查结论为 `BLOCK`，必须关闭：

1. prune 未严格验证 point，损坏/伪造 point 可能导致误删有效备份。
2. SQLite 只做 quick/integrity/FK/count，缺正式 schema10、trigger、index 和 runtime invariant 验证。
3. SQLite 与 Public projection pointer/generation/manifest 未形成共同恢复边界。
4. RPO 时间使用完成时间，可能把陈旧数据伪装为新恢复点。
5. 远端 consume 缺持久 tombstone/幂等收据，断链后可能半消费。
6. 加密对象身份未绑定 kind/keyId，路径和 immutable/O_EXCL 闭包不足。
7. Projection verifier 比生产 strict schema 宽松。
8. stale `run.lock` 可能让备份永久静默停止。

修复并通过 disposable 故障注入前，禁止安装备份 LaunchAgent、写 production recovery fence 或宣称已形成 verified recovery point。
