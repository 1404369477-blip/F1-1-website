## 1. 合同结论与优先级

本合同把用户已确认并冻结的 v0.2 Demo 转换为开发可逐项实现、测试可逐项验收的产品合同。实现发生冲突时按以下优先级处理：

1. `docs/spec.md` 的 accepted 领域、API、安全和外部门禁；
2. 本合同的页面行为、响应式与用户可见验收出口；
3. 上述固定路径、固定 hash 的冻结 HTML，作为视觉和交互细节的唯一证据；
4. 2026-08-07 的 `design/ui/F1+1-v0.2-实现级设计合同.md` 仅作早期版本历史，不覆盖本合同。

冻结 HTML 中的 `v0.2 DRAFT`、调试工具、证据导出控件和强制状态参数属于设计验证设施。生产实现必须移除或由不可达的开发开关隔离，不得把它们转化为公开产品功能。

## 2. MVP 边界

### 2.1 本轮必须实现

- 公开信息流单列时间线及其深浅主题、响应式、内容展开、多图导航、lightbox、展示状态与无障碍降级。
- 桌面右下角工具与中小视口底部 Dock；设置面板只承载已定义的骨架和主题操作。
- 继续消费当前 accepted projection-first `GET /api/public/feed` 与 `GET /api/public/stories/{publicId}`；UI 不得自行推导或新增公开 DTO 字段、领域实体或第二数据真值。已确认多图所需的版本化 DTO 变化只能经数据 successor 机器包、独立运行 profile、窄范围 accepted 合同和显式 V1/V2 协商后进入实现；同一响应不得混合版本，冻结 `public-synthetic` v0.4 不得被新 profile 改写或混跑。
- 继承既有“只过滤当前已加载时间线条目”的客户端搜索；不新增后端搜索、搜索实体或跨分页全量检索。

### 2.2 本轮禁止新增

- 本 UI 切片自行新增页面、主流程、领域实体、数据库表、后端设置模型、公开 API、搜索索引或发布真值。经独立数据任务和窄范围 successor 接受的版本化多媒体 DTO 不属于 UI 自行扩张。
- 语言、来源偏好、通知、显示密度的保存、权限或后端行为；这些仅可呈现为不可交互占位。
- 真实 Base/provider 切换、真实采集、真实表单提交、自动发布、部署、付费或外部写入。
- `DEMO_STORIES`、静态前端数据回退或任何绕过公开投影链的第二真值。

## 3. 页面与信息结构

### 3.1 时间线

- 页面主体为居中的单列时间线，桌面最大宽度 `920px`；宽屏不增加第二内容列。
- 桌面时间轴位于条目左侧；日期、时刻与条目内容保持视觉对齐。
- 条目阅读顺序固定为分类/直播标记、标题、完整摘要、主图、展开内容、证据行。
- 摘要完整展示，禁止 line-clamp 截断。
- 证据行显示信源、可空作者、时间和行内“前往原文”；作者为空时不渲染多余分隔符。
- feed 排序、稳定身份、原文 URL、来源和媒体均来自既有公开 DTO；UI 不猜测、不补造字段。

### 3.2 390px 移动端

- 日期和时间移至条目上方；标题、摘要、主图、展开内容和证据行按文档流排列。
- 四图条目仍保持来源证据与缩略图在同一行：来源文本可换行，右侧动作组不收缩，缩略图为 `22px`。
- 页面必须预留 Dock、系统安全区和最后一条内容所需的底部空间，避免永久遮挡。

## 4. 响应式工具与设置

### 4.1 1440px 桌面工具

- “回到顶部 / 设置 / 主题”作为同排无框文字工具固定在视口右下角。
- 默认使用低强调文字，无外框，保留冻结快照定义的轻微 text-shadow；hover/focus 使用 accent 与清晰焦点。
- 外层容器不得吞掉下方页面点击，三个按钮本身必须可交互。

### 4.2 `<=1100px`、1024px 与 390px Dock

- 工具转换为底部 Dock；模糊/渐变背板属于 Dock 的交互区域，必须截获点击，禁止穿透到时间线。
- 底部间距使用 `env(safe-area-inset-bottom, 0px)`。
- 设置面板展开时 Dock 与内容仍可辨认、可操作，不得覆盖关键恢复动作。

### 4.3 设置与主题边界

- 设置按钮切换面板；点击设置按钮或面板之外的页面区域关闭面板。
- 主题是设置按钮旁唯一独立、可工作的偏好操作；按钮文案和可访问标签反映当前主题。
- 深色为默认主题，浅色可切换；可沿用既有本地主题持久化，不新增服务端设置。
- 语言、来源偏好、通知、显示密度只显示不可交互占位，不保存、不调用 API、不创建实体。

## 5. 条目展开、多图与 lightbox

### 5.1 手风琴

- 同一时刻只允许一个条目展开；打开新条目会关闭旧条目。
- 点击当前展开条目之外的页面区域关闭该条目。
- 打开后将整个条目滚动到视口垂直居中；`prefers-reduced-motion` 时立即定位。
- 触发器使用原生按钮语义，并同步 `aria-expanded` 与 `aria-controls`。

### 5.2 主图与缩略图

- 每个条目只展示一张主图；多图缩略图位于证据行右侧并与来源证据底部对齐。
- hover 缩略图临时预览，leave 恢复已固定图，click 固定选择；Enter/Space 与点击等价。
- 主图支持 pointer、touch 和 trackpad 横向滑动；垂直手势交给页面滚动。
- 一次手势最多翻一张；共享手势锁防止重复翻页；发生滑动后抑制随后的误点击。
- 单图条目不渲染无意义的缩略图组。

### 5.3 Lightbox

- 点击主图或用键盘激活主图打开 `role=dialog`、`aria-modal=true` 的 lightbox。
- 支持前后按钮、左右方向键、Escape、pointer/touch/trackpad 横向滑动；一次手势最多翻一张。
- 打开时焦点进入对话框，Tab/Shift+Tab 留在对话框内；关闭后焦点返回触发元素。
- 点击对话框背景可关闭；多图显示当前位置；reduced-motion 下取消缩放与过渡。

## 6. 展示状态

时间线视图之外必须覆盖 `loading`、`empty`、`error`、`404`、`nomore`、`partial`、`offline` 七类展示状态。它们是 UI view state，不写入领域 enum、数据库或 API DTO。

- 每个状态只给一个清晰的主要说明和一个恢复/主动作。
- `partial` 明确已显示内容可能不完整；`offline` 不伪造在线成功。
- 搜索无结果属于独立的客户端搜索空态，不能复用后端 `empty` 语义。
- 失败时依据 accepted API/Problem 合同 fail closed；禁止回退静态 Demo 数据。

## 7. 主题、可访问与降级

- 全部交互目标最小 `44×44px`，键盘焦点可见；使用原生语义、可读标签及状态关联。
- 状态和选中不能只依赖颜色；深浅主题均满足既有对比度合同。
- `prefers-reduced-motion` 取消非必要动画；`prefers-reduced-transparency` 或不支持 blur 时使用不透明表面。
- `forced-colors` 下保留结构、焦点和状态可辨认性；200% 缩放不得产生页面级横向滚动或遮挡主操作。
- 外部字体、远程媒体或 blur 不可用时，内容和恢复动作仍可读、可操作；媒体权利、代理、自托管和生产离线策略仍是独立门禁。
