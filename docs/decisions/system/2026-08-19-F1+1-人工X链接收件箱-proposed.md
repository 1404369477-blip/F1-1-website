# F1+1 人工 X 链接收件箱

用户 2026-08-19 23:32 确认推进「人工贴帖、定时消化」，且不得用 cookie / RSSHub / Nitter / twikit 去翻时间线。

## 决定

1. **发现仍由人做。** 把已知公开帖 URL 写入本机 drop 文件；worker 不登录 X、不读 cookie、不轮询 59 个账号。
2. **消化只走官方 oEmbed。** 唯一外连是 `https://publish.x.com/oembed`，`omit_script=true`。抽出纯文本与作者，丢弃 iframe / script。不把 HTML 嵌进时间线。`publish.twitter.com` 现会 301，本切片直接打现行官方主机，不跟随任意 Location。
3. **独立 sidecar 库。** 数据写在 `~/Library/Application Support/F1Plus1/TweetInbox/inbox.sqlite`，**不写入**现行 RSS 审核库。现行 `source` 表仍只允许 Motorsport / Autosport；Admin / 投影 DTO 仍只认 RSS。
4. **本切片不自动发布、不存图。** 收据固定 `media: none`。社交图仍等 media-policy successor。
5. **本切片不安装 LaunchAgent。** 先手动 `npm run tweet-inbox-once`。定时器与审核入库是后续独立任务。

## 回退

删除 `TweetInbox` 目录与本模块即可；RSS 采集、审核、公开站不受影响。
