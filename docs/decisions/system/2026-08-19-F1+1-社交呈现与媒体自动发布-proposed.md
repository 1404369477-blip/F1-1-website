# F1+1 社交呈现与媒体自动发布

用户 2026-08-19 13:07 锁定两条产品方向；13:49 选定呈现 **B 图先行**。本文件不授权 X API、图片代理、审核库迁移或自动发布门放宽。

## 呈现裁定

时间线采用 Demo B：赛事新闻仍是标题 + 两行导语 + 折叠 96×64 露图，展开后再出主图和中文提炼。车手社交 / 名宿历史 / 赛场趣事折叠态先出主图，一句中文，展开只露 `原帖`，不写三点通讯稿。不采用 A 同壳、C 海报压字、D 挂事件。

## 决定

1. **时间线不嵌入官方推文 / X iframe。** 社交内容用站内卡片：图在前、一句中文、眉题「车手社交」、证据行 `Handle · 原帖`。详情页「看原帖」只有在签名代理失败、视频或不能热链时，才允许官方 embed 作为降级，不得作为时间线默认形态。
2. **规则筛选 → 审核 → 自动发布。** 社交和带图内容不是「永远只人工点发布」，也不是「抓到就倒进时间线」。先走确定性规则，再进审核队列，通过后由系统自动发布。

## 现行冲突（必须另开 successor，不得 silently 放宽）

- v4 自动发布：任一非空 media 固定 `MEDIA_POLICY_UNKNOWN` / `waiting`；只有精确 0 图路径可系统发布。
- 公开投影 `media.max(1)`；v0.2 卡片已支持 0/1/4，图是主展示。
- P-05：官方媒体 URL 或签名代理优先，不长期热链 `pbs.twimg.com`，不把原图当 CDN 存盘。

因此「要图 + 要自动发」必须先有独立的 **media-policy successor**：白名单来源、HTTPS、MIME/字节门、签名短 TTL 代理、删除/转私密下架。未 accepted、未实现前，0 图自动发布门保持不变。
