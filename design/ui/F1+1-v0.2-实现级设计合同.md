用法约束：

1. 内容层使用实色表面（`--surface`/`--bg-elev`）；玻璃只用于悬浮工具与 toast（§2.4）。
2. 中性色占主体；`--accent` 表达交互（链接/选中/焦点）；`--signal` 仅表达直播/品牌圆点。每屏每个强调色至多出现两次。
3. 状态必须有文字或图标，禁止只靠颜色区分。
4. 对比度约束引用 §6.3（WCAG 复核表）：文本 AA ≥4.5:1（大文本 ≥3:1）、非文本控件边界 ≥3:1。

### 2.4 玻璃材质（克制）与降级链

| Token | 值 | 用途 |
|---|---|---|
| `--glass-bg` | 深 `oklch(0.205 0.012 252 / 0.55)` / 浅 `oklch(1 0 0 / 0.5)` | 悬浮工具 FAB/面板 |
| `--glass-bg-strong` | 深 `oklch(0.205 0.012 252 / 0.85)` / 浅 `oklch(1 0 0 / 0.85)` | toast |
| `--blur` | **16px**（低性能端 8px） | `backdrop-filter: blur(var(--blur)) saturate(160%)` |
| `--glass-border` | 白 10% / 黑 8% | 玻璃发丝边 |
| `--glass-hi` | `inset 0 1px 0` 高光 | 玻璃顶部高光 |

降级链（顺序）：

1. `prefers-reduced-transparency: reduce` 或强制降级标记 → `background: var(--surface)`、`backdrop-filter: none`（不透明表面）。
2. 低性能（`@media (update: slow), (pointer: coarse) and (max-width:700px)`）→ `blur(8px) saturate(140%)`。
3. `backdrop-filter` 能力缺失 → 同 1 回退不透明 `--surface`。

> 注：`brand-spec.md` 曾写 `--blur: 18px`；本以 `token-map.json` / `design-system.md` / `index.html` 一致的 **16px** 为权威值，18px 差异记录于产品部报告“回指设计部”节。

## 4. 交互契约

### 4.1 URL 参数

| 参数 | 值 | 契约 | 生效层级 |
|---|---|---|---|
| `theme` | `dark` \| `light` | 初始主题；缺省 `dark`；写 `html[data-theme]`；切换持久化到 localStorage（键 `f1p1-theme`） | 生产公开页 |
| `open` | 条目稳定 id（草案 `r1…r10`；生产为 feed 项 `public_id`） | 预展开并高亮该条目（`#tl.is-focusing`），不自动滚动；无匹配时忽略 | 生产公开页（深链） |
| `search` | 任意文本 | 初始搜索过滤词；渲染后对已加载条目应用过滤 | 生产公开页 |
| `width` | `1440\|1024\|390` | **draft 调试/QA 专用**：在固定画布内模拟断点（`.app` 宽度 + 侧边框）。生产按真实视口，不使用该参数 | 仅 draft |
| `state` | `timeline\|loading\|empty\|error\|404\|nomore\|partial\|offline` | **draft 调试/QA 专用**：强制渲染指定状态用于证据导出与回归。生产由真实数据/API 驱动，不暴露为公开 URL 能力 | 仅 draft（dev 可保留为受控 QA 开关） |
| `reveal` | `1` | **draft 专用**：强制所有 `.trace` 痕迹显形（`html[data-reveal=true]`），用于导出“浮现”态证据 | 仅 draft |

实现要求：

- hash 参数解析用 `location.hash` 分隔 `&`/`=`，值 `decodeURIComponent`；写回用 `history.replaceState`（沙箱友好，失败 noop）。
- `state !== 'timeline'` 时删除 `open`（避免状态页残留展开参数）。
- draft-only 参数在公开生产构建中不注册为对外能力；保留作为 QA/证据开关时必须以开发开关显式隔离。

### 4.2 就地展开（手风琴）

- 触发：`.tl-summary-btn`（原生 `<button>`，整条为按钮）。点击 → 切换展开。
- 一次一个：打开某条目时，移除其他条目的 `is-open`，置 `aria-expanded="false"`。
- 状态同步：`aria-expanded` / `aria-controls=det-{id}` / 展开箭头旋转。
- 展开聚焦：打开时给 `#tl` 加 `.is-focusing` → 展开条目高亮（标题 `--accent` + 浅底），**其余条目降对比** `opacity:.38 + grayscale:.85`（触屏 `.5/.7`）。
- 滚动：展开动画结束后 `scrollIntoView({block:'start'})` + `scroll-margin-top:20px`（标题保持在视口顶部）；`prefers-reduced-motion` 时 `behavior:'auto'` 且不延迟。
- 点击外部收起：文档级 click 监听，点击当前展开 `.tl-item` 核心区之外 → 收起并删除 URL `open` 参数。
- 键盘：焦点在条目按钮上 Enter/Space 触发（原生 button 语义，无需额外 JS）。

### 4.3 缩略图导航（悬停预览 / 点击固定）

- **悬停预览**：`mouseover` 缩略图 → 主图临时切换为该缩略图 `src`/`alt`（仅当与当前激活 `data-cur` 不同）。
- **移走恢复**：`mouseout` 缩略图 → 主图恢复为当前激活（`.is-active`）缩略图对应的 `src`/`alt`。
- **点击固定**：点击缩略图 → 主图永久切换为该图、该项标记 `.is-active`、更新 `data-cur`；悬停预览基准随之更新。
- **键盘固定**：焦点在缩略图（`tabindex=0`）上按 Enter/Space → 同“点击固定”。
- **单图内容**：`imgs.length === 1` 时不渲染 `.ph-thumbs`，主图即为唯一图。
- 轻量化：`mouseover`/`mouseout` 用事件委托（文档级监听），避免每条目重复绑定。

### 4.4 lightbox（打开 / 关闭 / 焦点管理）

- **打开**：点击 `.ph-main`（或焦点在主图上按 Enter/Space）→ 从该图当前屏幕位置缩放放大到居中全彩（340ms），背景 `.app` 渐变 `grayscale(.85) blur(4px) opacity(.35)`。
- **内容**：`role="dialog" aria-modal="true"` + 可读 `aria-label`；`<img>`（max 70vw/70vh）；多图时 ‹› 翻页按钮 + `lb-count`（`aria-live="polite"`，格式 `N / M`）；单图隐藏翻页。
- **翻页**：‹› 按钮 / `ArrowLeft` / `ArrowRight`；序号取模回绕；翻页时图片 `opacity` 淡入（reduced-motion 跳过）。
- **关闭**：Esc / 点击背景（lightbox 容器空白处）→ 淡出 180ms，移除 `body.lb-open`，**焦点返回触发元素**（原主图/缩略图）。
- **焦点管理（合同要求）**：
  1. 打开时焦点移入 lightbox（容器 `tabindex="-1"`，打开后 `focus()`）。
  2. 关闭时焦点返回触发元素（`lastTrigger.focus()`）。
  3. **Tab/Shift+Tab 在 lightbox 内循环**（焦点陷阱）：可聚焦项为翻页按钮（+ 建议的关闭按钮，见回指设计部）。
  4. `reduced-motion`：跳过缩放/淡入淡出动画。
- 无障碍缺口记录：草案 lightbox **无显式关闭按钮**，且 `index.html` 未实现完整焦点陷阱（仅 focus 进 + 返回）。合同已规定必需行为（焦点陷阱 + 返回触发点 + Esc）；是否新增可见关闭按钮由设计部确认，见产品部报告“回指设计部”节。

### 4.5 搜索（客户端过滤）

- `input` 事件 → 按 `item.textContent` 子串（大小写不敏感）过滤 `#tl .tl-item`。
- 无匹配 → 显示“没有匹配的条目”（`role="status"` 或 `aria-live` 轻量提示），有匹配时隐藏。
- 过滤词同步进 URL `search` 参数；重渲染（主题/状态切换）后重新应用。
- 边界：仅过滤**已加载**条目（配合分页即当前页内过滤）；不新增后端搜索实体（§1.1）。

### 4.6 主题 / 宽度 / 状态（draft 控制 + 生产主题）

- 主题：`html[data-theme]` + `body[data-theme]`；seg 选中态 `aria-pressed`/`.is-active` 同步；持久化 localStorage。
- 宽度 / 状态：仅 draft 工具（§4.1 `width`/`state`）驱动，供证据导出与回归；生产不实现这两个用户能力。

### 4.7 证据行与「前往原文 ↗」

- 证据行文本（11.5px faint）：`信源 · [作者] · 时间`；**无作者时不渲染作者段**（含分隔符）；`unknown` 不渲染（作者缺失时跳过该段）。来源/作者/时间**直接显示有效信息，不带「来源」「作者」「原发」等说明标签**。
- 「前往原文 ↗」：`--accent` 文本链接、`min-height:44px`、hover 下划线；**生产为真实 `<a href="source_evidence_url">` 普通导航**（浏览器打开原文，无服务器 fetch、无重定向代理）。`target="_blank"` 时加 `rel="noopener noreferrer"`。M4 测试仍 `external_calls=0`（导航不触发服务端外联）。

## 5. 响应式（1440 / 1024 / 390）

实现载体：`.app { container-type: inline-size }` + `@container (max-width:700px)`，`@media (max-width:700px)` 兜底；**无页面级水平滚动**。

| 宽度 | 布局 |
|---|---|
| **1440** | 单列居中（`.app` 壳层 clamp 边距，时间线 max 920px）；发丝轴在左（`left:78px`）；条目栅格 `64px 1fr` gap 24px；节点圆点位于日期列与内容之间（`left:74px top:34px`，9px，`--border-strong` 1.5px 边，`--bg` 底）；单张主图（原始比例限高 255px）+ 40px 缩略图 |
| **1024** | 与 1440 **相同单列**；不改变列数、不拥挤 |
| **390** | 单列重排：**时间/日期并排**（日期在前，`flex-direction: row-reverse`、baseline），发丝轴与节点隐藏；日期 18px；主图限高不变、缩略图 **32px**；触控目标 ≥44px；DRAFT 徽标隐藏；搜索框 72px（focus 120px） |

触屏辅助：

- `@media (pointer: coarse)`：`.trace` 基准对比提升到 `.85`（无 hover 时避免不可发现）。
- 展开聚焦降对比降级：触屏 `.5/.7`（替代指针设备的 `.38/.85`）。

## 6. 可访问与降级

### 6.1 键盘可达

- 所有功能键盘可达：条目按钮（原生 `<button>`）、缩略图/主图（`tabindex=0` + Enter/Space）、搜索、主题 seg、lightbox（Esc/方向键）。
- `.trace` 控件 `:focus-visible` 同样浮现（与 hover 同级）。

### 6.2 焦点管理

- `:focus-visible`：**3px `--focus` 外环 + 2px offset**，全局可聚焦元素（含条目按钮）。
- lightbox：进入/返回触发点 + 焦点陷阱（§4.4）。
- 展开聚焦：`.is-focusing` 下其余条目降对比/灰度（不抢占阅读焦点，展开条目标题 accent）。

### 6.3 对比度（引用对比度验证表）

`F1+1-v0.2-对比度验证.md` 已按 WCAG 2.2（文本 AA ≥4.5:1、大文本 ≥3:1、非文本控件边界 ≥3:1）复算，**深/浅双主题全部通过**：

| 深色（基准 `--bg` ≈ #000a0d） | 浅色（基准 `--bg` ≈ #f3f5f8） |
|---|---|
| `--fg` 16.60:1 ✅ | `--fg` 15.87:1 ✅ |
| `--fg-strong` 18.96:1 ✅ | `--fg-strong` 18.26:1 ✅ |
| `--muted` 6.88:1 ✅ | `--muted` 6.53:1 ✅ |
| `--faint`（11.5px 证据）5.02:1 ✅ | `--faint` **4.64:1** ✅（临界，勿再降） |
| `--accent` on `--bg` 8.36:1 ✅ | `--accent` on `--bg` 6.13:1 ✅ |
| `--accent` on `--surface` 7.56:1 ✅ | `--accent` on `--surface` 6.68:1 ✅ |
| `--signal` 6.93:1 ✅ | `--signal` 5.91:1 ✅ |
| `--border-strong` **3.03:1** ✅（非文本，修正后） | `--border-strong` **3.08:1** ✅（非文本，修正后） |

实现约束：

- 浅色 `--faint`（4.64:1）接近下限：证据小字不得继续降透明度/亮度。
- 悬停浮现：**前景亮度不降、对比不降**（`opacity`/可见度变化 + `--accent`，正文/日期/证据链始终全对比）。
- 未覆盖项需在真实内容复验：图片上的文字（最亮/最暗裁切区）、玻璃表面（悬浮工具/toast）文字对比——草案用占位图，真实摄影未测（见 §10 未验证）。

### 6.4 触控目标

- 所有交互目标 ≥44px：主图放大（44px 命中区）、缩略图（`height` 视觉 40/32px，建议命中区扩展 ≥44px）、前往原文、lightbox 翻页按钮（48px）、条目按钮、搜索、主题 seg 按钮、FAB。
- 后台/桌面紧凑控件不得在触控断点保留 <44px。

### 6.5 降级媒体与运动

| 场景 | 实现 |
|---|---|
| `prefers-reduced-transparency: reduce` | 玻璃 → `background: var(--surface)`、`backdrop-filter:none` |
| `prefers-reduced-motion: reduce` | 过渡/动画 → `.01ms`；lightbox 缩放与淡入淡出、展开动画跳过；滚动 `auto`；直播圆点静止；`.trace`/`.tl-caret` 取消 scale（保留对比度变化）；搜索框保持展开态 |
| 低性能设备 | `blur(8px) saturate(140%)`（`(update:slow)` 或触屏窄屏） |
| 强制显示 | `forced-colors: active` 取消玻璃模糊，用系统颜色/轮廓/文本状态 |

### 6.6 语义与图片

- 时间线为 `section` + `ol`/`li`；主内容 `main`。
- 图片 alt：真实图 `配图 N + 主题` 或主题描述；纯装饰点阵/渐变 `aria-hidden="true"`。
- 时间列 `aria-hidden="true"`（装饰），真实时间写入证据行。
- lightbox `role="dialog" aria-modal`；toast/状态提示 `aria-live="polite"` 不抢焦点。
- 状态必须文字 + 图标（或明确文本），不单靠颜色。

## 7. 状态矩阵

| 状态 | 前景/背景 | 展示 | 主要动作 |
|---|---|---|---|
| `loading` | 骨架 `--surface-2` | 与时间线同构骨架（时间块 56×26 + 3 行文本块 78%/100%/54%），shimmer 1.4s（reduced-motion 关闭） | 无 |
| `timeline` | — | 时间线正常渲染 | 展开/lightbox/搜索 |
| `empty` | 状态码 `0` | “暂无内容” + “当前没有可显示的聚合内容。” | `刷新 →` |
| `error` | 状态码 `!` | “加载失败” + “聚合服务暂时不可用，请稍后再试。” | `重试 →` |
| `404` | 状态码 `404` | “未找到这条内容” + “链接可能已失效。” | `返回时间线 →` |
| `nomore` | 状态码 `∅` | “已无更多内容” + “已经到底了，没有更多聚合内容。” | `返回顶部 →` |
| `partial` | 状态码 `i` | “部分内容加载成功” + “部分内容加载成功，部分失败；可重试失败项。” | `重试失败项 →` |
| `offline` | 状态码 `ⓘ` | “离线 / 受限” + “当前网络受限，展示最近可用信息。” | `刷新 →` |

- 状态盒：`state-box` 居中，44px display 状态码 `--accent`，16px/600 标题 `--fg`，13.5px 消息 `--muted`，操作链接 44px。
- 每状态**仅一条返回路径**（原则：一个动作、一个主路径）。
- 骨架：保持与真实条目相同比例与行数，避免布局跳动。

## 8. 悬停浮现（Progressive Reveal）

| 层级 | 状态 | 实现 |
|---|---|---|
| 低对比常驻 | 默认 | `.trace` 统一 `opacity:.5`；顶栏内控件鼠标进入顶栏先浮现到 `.85` |
| 悬停浮现 | `.trace:hover` | `opacity:1` + `scale(1.04)`，150ms ease-out |
| 键盘聚焦 | `.trace:focus-visible` / `.search:focus-within` | 同全对比 + 微放大；搜索整组一并浮现 |
| 触屏 | `@media (pointer:coarse)` | 基准对比提升到 `.85` |
| 减少动效 | `prefers-reduced-motion` / 强制降级 | 取消 scale，只保留对比度/可见度变化 |
| 证据/调试 | `#reveal=1`（`html[data-reveal=true]`） | 全部痕迹强制显形（不带动效） |

覆盖范围：顶栏标记、主题 seg、搜索框、悬浮工具 FAB、条目展开指示（`.tl-caret` hover/focus 从 `.35` 浮现到 `.9`）。**日期、标题、摘要、证据链不受低对比影响**（始终全对比）。
