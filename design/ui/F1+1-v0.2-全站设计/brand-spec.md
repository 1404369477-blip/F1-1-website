# F1+1 · v0.2-draft · Brand Spec（品牌规格草案）

> 本文件是 v0.2-draft 的品牌规格提取，**仅用于设计草案**，不覆盖 v0.1 冻结规范、不改动正式 app / Spec / ADR。来源：v0.1 已冻结全站设计规范（内容优先 · 专业克制 · Apple OS 系统骨架 + BMW M 硬朗编辑 · 默认深色可切换浅色）。本迭代为 v0.2-draft 的「时间线优先」收敛。

## 一句话总结

F1+1 v0.2 时间线迭代把全站收敛为「信息 + 时间 + 时间线」：一条纵向时间轴是唯一核心，时间标记是主要视觉线索，视觉层级压到「时间轴 → 条目 → 证据小字」三层；移除顶部导航、品牌字标、hero、分类筛选条等一切干扰。必要的 UI 痕迹（顶栏工具、搜索、功能按钮、展开指示）以「悬停浮现」方式低对比常驻，需要时显形。玻璃材质仅保留在悬浮工具与 toast，时间线主体用实色表面；默认深色并提供完整浅色。

## Font stacks

- **Display（标题 / 数字 / 索引）**：`"Barlow Condensed"`（600–800）→ `"Source Han Sans CN" / "思源黑体 CN"` → `"PingFang SC"`。中文标题落入 CJK 字重，保持硬朗编辑感。
- **Body（正文 / 摘要）**：`"Inter"`（400–600）→ `"Source Han Sans CN" / "思源黑体 CN"` → `"PingFang SC"` → 系统 sans。
- **Mono（数值 / 错误码 / token 标注）**：`"SF Mono" → "Menlo" → "Consolas"`。

> 不复制 Apple、BMW、F1 的商标、字体文件、图标、摄影或页面资产；字体均采用开放许可（Google Fonts Barlow Condensed / Inter，CJK 用系统字体），影像一律使用原创占位。

## 视觉语言规则（v0.1 继承 + v0.2 时间线收敛）

1. **信息 + 时间 + 时间线是唯一核心**：整页一条纵向时间轴；每项突出「发布时间 + 标题/摘要」，时间标记为主要视觉线索；内容倒序。
2. **层级压到三层**：时间轴 → 条目 → 证据小字；移除顶部导航、品牌字标、hero/lead 大卡、分类筛选条、胶囊按钮组、draft 设置面板；不依赖导航跳转，详情就地展开。
3. **玻璃克制**：仅悬浮工具与 toast 使用毛玻璃；时间线主体为实色表面，靠发丝线与留白建立层级。
4. **BMW M 影响收窄为三点**：标题/日期字重、紧凑编辑节奏、1px 速度感发丝轴；红蓝冷暖温差仅作克制点缀（直播圆点 / 交互蓝），每屏每个强调色至多出现两次。
5. **默认深色 + 完整浅色**：两套主题 token 完整、可对比、可一键切换（浅色强调色加深以满足 WCAG 4.5:1）。
6. **一个动作、一个主路径**：同屏唯一主操作是「前往原文」，以文本链接呈现（accent，不重复多次）；状态页仅一条返回路径。
7. **悬停浮现（Progressive Reveal）**：必要的 UI 痕迹（顶栏工具、搜索、功能按钮、展开指示）以低对比常驻；鼠标/键盘聚焦到功能点时浮现（全对比 + 微放大 1.04，150ms ease-out），点击触发。时间线正文/日期/证据链始终全对比，不受低对比影响。
8. **可访问降级为硬约束**：reduced-transparency 玻璃回退不透明；reduced-motion 取消位移/缩放/自动播放（悬停浮现仅保留对比度变化）；可见 3px 焦点环；44px 触控目标；触屏提升痕迹基准对比避免不可发现。
9. **图片为主、缩略图导航**：每条内容以单张主图（原始比例、限高、不裁切）+ 缩略图呈现；悬停缩略图预览、点击固定；单图内容不显示缩略图。真实内容以中文提炼呈现、保留原文语境；无作者不显示作者段。
